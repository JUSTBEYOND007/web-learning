代码简单 但是难理解  我们从上当下查找如果找到p 或者q 返回  从上往下递归 从下往上返回状态
即<font color="#007ACC">算法思路就是“从根节点向下递归查找 p/q（从上往下探索），从叶子节点或 p/q 开始返回状态并汇总到父节点（从下往上返回），最后在某个节点左右子树都找到了 p/q 时，该节点就是最近公共祖先”。
</font>`

`left` 和 `right` **不是直接表示祖先**，而是表示“左/右子树中找到的 p/q 或 LCA（最近公共祖先）
`left` 和 `right`在查找时返回时表示的找到的p或者q节点 当p和q都找到时执行


```
   if(left&&right)

        return root
```
 left或者right表示的就是最近公共祖先

```left或者right表示的就是最近公共祖先

```js
var lowestCommonAncestor = function(root, p, q) {

    if(!root||root===q||root===p)

        return root

    const left=lowestCommonAncestor(root.left,p,q)

    const right=lowestCommonAncestor(root.right,p,q)

    if(left&&right)

        return root

    else  return left?left:right

};
```
