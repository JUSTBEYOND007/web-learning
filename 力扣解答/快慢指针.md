```
let fast=head,slow=head
while (fast && fast.next) {
    fast = fast.next.next
    slow = slow.next
}
```
while结束后 `slow` 一定指向“后半部分链表的头结点”，  对奇数、偶数长度都成立（按常见定义）
奇数 `slow` 指向 **正中间节点（第 k+1 个）**
偶数 `slow` 指向右半部分第一个即 **第 k+1 个节点**


有的时候我们需要保存左半侧链表的最后一个节点 我们可以修改代码 让fast=head.next
slow就指向的是左侧最后一个节点
```
let slow = head
let fast = head.next

while (fast && fast.next) {
    slow = slow.next
    fast = fast.next.next
}
```
