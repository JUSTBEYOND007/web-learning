### JavaScript 中的集合类家族

除了 `Set` 和 `Map`，JavaScript (ES6+) 还提供了两种特殊的集合，统称为“强引用”和“弱引用”集合：

|**类型**|**特点**|**常用场景**|
|---|---|---|
|**`Set`**|存储**唯一值**的列表。|数组去重、求交集/并集。|
|**`Map`**|存储**键值对**（Key-Value），键可以是任何类型。|缓存数据、存储复杂的对象映射关系。|
|**`WeakSet`**|只能存储**对象**。成员是弱引用。|存储 DOM 节点，防止内存泄漏。|
|**`WeakMap`**|键必须是**对象**。键是弱引用。|在不修改对象本身的情况下，给对象关联数据（私有属性）。|

---

### 3. 补充：为什么要有 WeakSet 和 WeakMap？

这是 JS 内存管理的进阶知识。

- **弱引用（Weak Reference）**：如果你把一个对象放入 `Map`，只要 `Map` 还在，这个对象就不会被垃圾回收（即使没有其他地方引用它了）。
    
- **自动回收**：如果你把对象放入 `WeakMap` 作为键，当没有其他地方引用这个对象时，垃圾回收机制会**自动**把这个对象从内存和 `WeakMap` 中同时清除。
    

示例场景：

假设你在为一个网页上的按钮（DOM 对象）记录点击次数：

- 用 `Map`：如果按钮被删除了，你得手动从 Map 里删除它，否则它会一直占着内存。
    
- 用 `WeakMap`：按钮被删除后，内存会自动释放，非常省心。
