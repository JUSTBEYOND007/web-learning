我们使用双指针 分别指向两个数组的有效末尾
我们比较值 值大的放在num1的末尾 即可（因为长度为m+n 而且时升序排序 不会存在没有赋到正确位置 就覆盖掉的问题）
while(l2>=0) 直到 l2插入完l1中 


# 为什么必须写 `l1 >= 0`？

因为当 `l1 < 0` 时，说明：

### ✔ nums1 中「真实用户数据」已经用完了

### ✔ nums1 只剩下前面的位置等待被填充

### ✔ 此时应该全部从 nums2 里取数据
```js
var merge = function(nums1, m, nums2, n) {

    //双指针

    let l1=m-1,l2=n-1,cur=m+n-1

    while(l2>=0){

        if(l1>=0&&nums1[l1]>=nums2[l2]){

            nums1[cur]=nums1[l1]

            l1--

        }else{

            nums1[cur]=nums2[l2]

            l2--

        }

        cur--

    }

};
```
