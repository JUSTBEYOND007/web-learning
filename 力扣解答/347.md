在js中我们没有 小顶堆 的api  否则需要我们自己实现
我们可以使用桶排序的方法
我们先通过map来统计次数
创建桶数组  每一项为一个数组 数组长度 我们设置为数组元素出现的最大的频率+1（加上0）
相同频率的我们加入在桶的同一索引下
因为题目说结果唯一  所以我们直接最后for循环倒叙遍历桶数组加入到ans数组中 结果不会有问题
```js
var topKFrequent = function(nums, k) {

    const map=new Map()//map来统计 每个数字出现的频率

    for (const element of nums) {

        map.set(element,(map.get(element)??0)+1)

    }  

    const maxTimes=Math.max(...map.values())

    const buckets=Array.from({length:maxTimes+1},()=>[])//用bucket数组来模拟桶  索引为对应的频率 每个位置存在频率为索引的所有数组成的数组   我们从后往前遍历就是 大根桶

  

    for (const [key,times] of map.entries()) {

        buckets[times].push(key)

    }

    const ans=[]

    for (let index = buckets.length-1; index >=0&&ans.length<k; index--) {

        ans.push(...buckets[index])

    }

    return ans

};
```


```java
import java.util.HashMap;  
import java.util.Map;  
import java.util.PriorityQueue;  
import java.util.Random;  
class Solution {  
    public int[] topKFrequent(int[] nums, int k) {  
        HashMap<Integer,Integer> map=new HashMap<>();  
        for (int num : nums) {  
            map.put(num,map.getOrDefault(num,0)+1);  
        }  
        //创建小根堆  
        PriorityQueue<int []> MinHeap=new PriorityQueue<>((a,b)->a[1]-b[1]);//用数组表示键值对  'a,b)->a[1]-b[1]'为比较器的lambda表示 表示为小根堆 不写默认也是小根堆  
        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {  
            if(MinHeap.size()<k)  
                MinHeap.add(new int[]{entry.getKey(),entry.getValue()});  
            else {  
                if(entry.getValue()>MinHeap.peek()[1]){  
                    MinHeap.poll();  
                    MinHeap.add(new int[]{entry.getKey(),entry.getValue()});//加入之后会自动调整  
                }  
            }  
        }  
        int []ans=new int[k];  
        for (int i = 0; i < k; i++) {  
            ans[i]=MinHeap.peek()[0];  
            MinHeap.poll();  
        }  
        return ans;  
    }  
}
```

**时间复杂度**：遍历为n  每次都需要调整堆 需要logk（堆大小为k）

#### 实现机制

`PriorityQueue` 基于 **堆（Heap）** 数据结构实现，通常是一个完全二叉树：

  

1. **堆的特性**：
    
    - 每个节点的值都小于或等于其子节点的值（小根堆）
    - 堆顶元素始终是最小值
    - 使用数组表示，通过索引计算父子关系
2. **数组表示**：
    
    - 对于索引为`i`的节点：
        - 父节点：`(i-1)/2`
        - 左子节点：`2*i + 1`
        - 右子节点：`2*i + 2`

#### 加入操作（add/offer）

当添加新元素时，`PriorityQueue` 执行以下步骤：

  

1. 将元素添加到数组末尾
2. 执行 "上浮" 操作（siftUp）：
    - 比较新元素与父节点
    - 如果新元素更小，则交换位置
    - 继续向上比较，直到满足堆性质或到达根节点

  

这个过程的时间复杂度是 **O(log n)**，因为树的高度是 O (log n)。

#### 删除操作（remove/poll）

当删除堆顶元素时，`PriorityQueue` 执行以下步骤：

  

1. 保存堆顶元素（将被返回）
2. 将数组末尾元素移到堆顶
3. 执行 "下沉" 操作（siftDown）：
    - 比较堆顶元素与两个子节点
    - 如果堆顶元素大于较小的子节点，则交换位置
    - 继续向下比较，直到满足堆性质或到达叶子节点

  

这个过程的时间复杂度也是 **O(log n)**。
