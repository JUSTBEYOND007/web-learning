answer[i] 等于 nums 中除了 nums[i] 之外其余各元素的乘积

引入概念 前缀积（i之前元素的积）和后缀积（i之后元素的积）
answer[i] =前缀积 *  后缀积

本应该创建两个数组记录前缀积和后缀积  但是我们可以直接记录到res 结果数组中 这样为O(1)

```
var productExceptSelf = function(nums) {

    let prefix=1,post=1//初始化为1重点 不是初始化为0  
	
    const res=[]

    for(let i=0;i<nums.length;i++){//前缀积从前往后

        res[i]=prefix//保存当前元素的前缀积

        prefix*=nums[i]//计算下一个元素的前缀积

    }

    for(let i=nums.length-1;i>=0;i--){//前缀积从后往前

        res[i]*=post

        post*=nums[i]

    }

    return res

};
```
