_滑动窗口中的最大值_ 。 题较难想到方法 我们记住解决方法即可

我们用数组（来模拟双向队列 满足非递增序列 是前面的元素>=后面的元素 ）来保存可能的最大值（保存的是数组角标）
要求满足：
1.<font color="#007ACC">每次遍历到一个新值时，要做一个事情，删除队列中所有比这个值小的值</font>，因为这个值入队之后，所以比这个值小的，并且在这个值之前的，都不可能是答案。


2.另外，不管最新遍历到的这个值，大小如何，都要加入队列。因为这个值有可能是后面的答案。

```
var maxSlidingWindow = function(nums, k) {

    const q=[]

    const result=[]

    for(let i=0;i<k;i++){  //未形成窗口时

        while(q.length>0&&nums[q[q.length-1]]<nums[i]){

            q.pop()

        }

         q.push(i)

    }

    result.push(nums[q[0]])//第一次的窗口值

    for(let i=k;i<nums.length;i++){//形成窗口后 向后遍历

     if(q[0]<(i-k+1))//或者if(q[0]==(i-k)) 就是q[0]保存的是滑动窗口的前一个数组角标

            q.shift()

        while(q.length>0&&nums[q[q.length-1]]<nums[i]){

            q.pop()

        }

         q.push(i)

         result.push(nums[q[0]])

    }

    return result

};
```
