前缀和+map
前缀和包括当前i下表的数组值


这里要重点记住前缀和的方法   子数组=前缀和 - 前面下标索引的前缀和


利用前缀和将“子数组和为 k”  
转化为“两个前缀和之差为 k”，  
再用哈希表统计前缀和出现次数，  
实现 O(n) 时间复杂度求解。


```
var subarraySum = function(nums, k) {

    const map=new Map()

    map.set(0,1)//注意这里！！！ 要考虑从0索引开始 既有初始情况 和为0的情况一种 即前缀索引为0

    let curSum=0

    let ans=0

    for(let i=0;i<nums.length;i++){

        curSum+=nums[i]

        if(map.has(curSum-k))

            ans+=map.get(curSum-k)//以当前i结束的符合的子数组

        map.set(curSum,(map.get(curSum)||0)+1)

    }

    return ans

};
```

## 1. `map.get(key)` 的返回值

- 如果 `key` 在 `Map` 中存在，返回对应的 **value**。
- 如果 `key` 在 `Map` 中不存在，返回 **`undefined`**。
