1. 基本规则

异或按位比较两个数字：

- 两位不同，结果为 `1`
- 两位相同，结果为 `0`


- **x ^ x = 0**  
    相同数字异或等于 0。
    
- **x ^ 0 = x**  
    任何数与 0 异或等于其本身。
    
- 不同数字的异或 逐位比较两个数的二进制，相同为 0，不同为 1。

```js
var singleNumber = function(nums) {

    let res=0//初始化为0  任何数与 0 异或等于其本身。 顺利从第一个元素开始

    for (const element of nums) {

        res=res^element

    }

    return res

};
```
