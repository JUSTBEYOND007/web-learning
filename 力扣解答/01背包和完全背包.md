### 🚀 核心对比表

<font color="#9B59B6">重点：两层 for 循环我们都按照“外物品重量、内背包容量”顺序。完全背包必须从前往后遍历，01 背包必须从后往前遍历。</font>

`dp[j]` 表示 **背包容量为 j 时，可以获得的最大价值**


| 特性         | **01 背包** (每件物品选 1 次)             | **完全背包** (每件物品选无限次)               |
| :--------- | :-------------------------------- | :-------------------------------- |
| **物品限制**   | 只能选 0 或 1 次                       | 可以选 0, 1, 2, ... k 次              |
| **二维数组遍历** | 顺序随意 (通常先物后包)                     | 顺序随意 (通常先物后包)                     |
| **一维数组遍历** | **容量必须倒序** ($W \to w_i$)          | **容量必须正序** ($w_i \to W$)          |
| **状态转移方程** | `dp[j] = max(dp[j], dp[j-w] + v)` | `dp[j] = max(dp[j], dp[j-w] + v)` |
| **底层逻辑**   | 依赖**上一轮**的状态 (防止重复)               | 依赖**本轮已更新**的状态 (允许重复)             |
| **典型应用**   | 偷窃问题、分割等和子集                       | 零钱兑换、爬楼梯、组合总和                     |
|            |                                   |                                   |

### 📦 模板一：01 背包 (One-Dimensional DP)

**场景**：有 $N$ 个物品，每个物品只有一个，背包容量为 $W$，求最大价值/是否可行/方案数。
#### 三种目标的对比
目标	dp[j] 含义	初始化	转移方程
最大价值	容量 j 能装的最大价值	全 0	dp[j] = Math.max(dp[j], dp[j-w] + v)
是否可行（能否装满）	容量 j 能否恰好装满	dp[0]=true，其余 false	`dp[j] = dp[j]
方案数	装满容量 j 的方案数	dp[0]=1，其余 0	dp[j] += dp[j-w]
规律：求最值用 max/min，求可行用「或」，求方案数用「加」。 初始化都是从「容量 0」这个 base case 出发。

#### 💻 代码模板 (JavaScript)

#### 求最大价值
```javascript
/**
 * @param {number[]} weights - 物品重量数组
 * @param {number[]} values - 物品价值数组
 * @param {number} capacity - 背包容量
 * @return {number} - 最大价值
 */
function knapsack01(weights, values, capacity) {
    const n = weights.length;
    
    // 初始化 dp 数组
    // 求最大值：初始化为 0
    // 求是否装满/方案数：通常 dp[0]=1, 其他=0
    const dp = new Array(capacity + 1).fill(0);//记住 长度是capacity + 1 记住要+1

    // 1. 外层遍历物品
    for (let i = 0; i < n; i++) {
        const w = weights[i];
        const v = values[i];

        // 2. 内层遍历容量 -> 【关键：倒序！】
        // 从 capacity 遍历到 w，保证 dp[j-w] 是上一轮的数据
        // 也就是 j 依赖的是 i-1 时刻的状态，避免同一个物品被加两次
        for (let j = capacity; j >= w; j--) {// 从 capacity 遍历到 w
            dp[j] = Math.max(dp[j], dp[j - w] + v);
        }
    }

    return dp[capacity];
}
```





#### 是否可行（能否恰好装满容量 W）
```javascript
function canFill(weights, capacity) {
  const dp = new Array(capacity + 1).fill(false);
  dp[0] = true;  // 容量 0 天然可行（什么都不装）

  for (let i = 0; i < weights.length; i++) {
    const w = weights[i];
    for (let j = capacity; j >= w; j--) {  // 倒序不变
      dp[j] = dp[j] || dp[j - w];
    }
  }
  return dp[capacity];
}
```
含义：dp[j] 为 true 表示「能选出一些物品，重量之和恰好为 j」。转移是「本来就行 dp[j]，或者去掉当前物品后剩下的 dp[j-w] 行」。

上一题分割等和子集就是这个模板，target 当作容量、每个数当作重量。

#### 方案数（有多少种选法恰好装满 W）
```javascript
function countWays(weights, capacity) {
  const dp = new Array(capacity + 1).fill(0);
  dp[0] = 1;  // 关键：装满容量 0 有 1 种方案（空集），是所有累加的种子

  for (let i = 0; i < weights.length; i++) {
    const w = weights[i];
    for (let j = capacity; j >= w; j--) {  // 倒序不变
      dp[j] += dp[j - w];
    }
  }
  return dp[capacity];
}
```
含义：dp[j] 表示凑出重量 j 的方案总数。转移 dp[j] += dp[j-w]：不选当前物品的方案数是原来的 dp[j]，选当前物品的方案数是 dp[j-w]，两者相加。

为什么 dp[0] = 1 而不是 0？ 这是整个累加的起点。如果 dp[0]=0，那所有 dp[j] += dp[j-w] 累加的全是 0，最后永远是 0。dp[0]=1 代表「空集」这一种合法方案，让后面的累加有东西可加。

为什么倒序对三种都成立
原因和求最值时完全一样：倒序遍历保证 dp[j-w] 用的是上一轮（不含当前物品 i）的值，从而每个物品只被用一次（01 背包的本质）。

如果正序，dp[j-w] 会先在本轮被当前物品更新过，导致当前物品被重复选 → 就变成完全背包（每个物品可用无限次）了。
反过来说：如果你要求完全背包（物品无限个），就把内层改成正序，方程不变。这是 01 和完全背包唯一的区别。
顺带一提：几道经典题的对应
分割等和子集 → 是否可行模板（能否装满 total/2）
目标和（加减号凑目标） → 方案数模板（转化成子集和 = (total+target)/2）
零钱兑换 II（凑金额的组合数） → 方案数模板 + 正序（完全背包，硬币无限）
零钱兑换（最少硬币数） → 求最值模板 + 正序，方程用 dp[j]=Math.min(dp[j], dp[j-coin]+1)
一句话总结你的问题：模板骨架不动，改「初始化」和「转移操作符」——最值用 max/min，可行用 ||，方案数用 +=，并且方案数记得 dp[0]=1。

#### 🔑 记忆口诀
> **“01 背包怕重复，内层循环倒着走。”**
> (因为正序会导致 `dp[j-w]` 已经被当前物品更新过，从而选了两次)

### 🔄 模板二：完全背包 (Complete Knapsack)

**场景**：有 $N$ 种物品，每种物品无限个，背包容量为 $W$，求最大价值/最小数量/方案数。

#### 💻 代码模板 (JavaScript)

```javascript
/**
 * @param {number[]} weights - 物品重量数组
 * @param {number[]} values - 物品价值数组
 * @param {number} capacity - 背包容量
 * @return {number} - 最大价值
 */
function knapsackComplete(weights, values, capacity) {
    const n = weights.length;
    
    // 初始化
    // 求最大值：初始化为 0
    // 求最小数量：初始化为 Infinity, dp[0]=0
    const dp = new Array(capacity + 1).fill(0);
    
    // 如果是求最小值，上面那行改为: 
    // const dp = new Array(capacity + 1).fill(Infinity);
    // dp[0] = 0;

    // 1. 外层遍历物品
    for (let i = 0; i < n; i++) {
        const w = weights[i];
        const v = values[i];

        // 2. 内层遍历容量 -> 【关键：正序！】
        // 从 w 遍历到 capacity，允许利用本轮刚更新过的 dp[j-w]
        // 也就是 j 依赖的是 i 时刻（当前）的状态，符合“无限取”的逻辑
        for (let j = w; j <= capacity; j++) {
            dp[j] = Math.max(dp[j], dp[j - w] + v);
            
            // 如果是最小值问题:
            // if (dp[j - w] !== Infinity) {
            //     dp[j] = Math.min(dp[j], dp[j - w] + v);
            // }
        }
    }

    return dp[capacity];
}
```
#### 1. 最小数量（凑满容量 W 最少用几个物品）
```javascript
function minCount(weights, capacity) {
  const dp = new Array(capacity + 1).fill(Infinity);
  dp[0] = 0;  // 凑满容量 0 需要 0 个物品

  for (let i = 0; i < weights.length; i++) {
    const w = weights[i];
    for (let j = w; j <= capacity; j++) {  // 正序
      if (dp[j - w] !== Infinity) {
        dp[j] = Math.min(dp[j], dp[j - w] + 1);  // +1 表示多用一个当前物品
      }
    }
  }
  return dp[capacity] === Infinity ? -1 : dp[capacity];  // 凑不出返回 -1
}
```
要点：

初始化 Infinity、dp[0]=0。求最小值必须用一个「不可达」的大值初始化，否则 min 永远选到 0。
dp[j-w] !== Infinity 的判断是防止 Infinity + 1 溢出成一个看似有效的值。
这就是零钱兑换（求最少硬币数） 的模板，+1 而不是 +v，因为求的是个数不是价值。
#### 2. 方案数 —— 这里有大坑：组合数还是排列数？
先给组合数（每种物品的集合算一种，不管顺序，最常见）：
```javascript
function countCombinations(weights, capacity) {
  const dp = new Array(capacity + 1).fill(0);
  dp[0] = 1;

  // 外层物品，内层容量正序  ← 这个顺序 = 组合数
  for (let i = 0; i < weights.length; i++) {
    const w = weights[i];
    for (let j = w; j <= capacity; j++) {  // 正序
      dp[j] += dp[j - w];
    }
  }
  return dp[capacity];
}
```
再给排列数（顺序不同算不同方案，比如 [1,2] 和 [2,1] 是两种）：
```js
function countPermutations(weights, capacity) {
  const dp = new Array(capacity + 1).fill(0);
  dp[0] = 1;

  // 外层容量，内层物品  ← 交换嵌套顺序 = 排列数
  for (let j = 0; j <= capacity; j++) {          // 外层遍历容量
    for (let i = 0; i < weights.length; i++) {   // 内层遍历物品
      if (j >= weights[i]) {
        dp[j] += dp[j - weights[i]];
      }
    }
  }
  return dp[capacity];
}
```
为什么循环顺序决定组合 vs 排列
这是完全背包方案数最核心、也最容易记混的一点：

外层物品、内层容量（组合数）：物品是一个个「加入考虑」的。处理完物品 A 再处理 B，所以 B 永远排在 A 之后被计入，[A,B] 和 [B,A] 只会被算成同一种（因为 A 处理完就不会回头）。→ 不计顺序 = 组合。

外层容量、内层物品（排列数）：对每个容量 j，都把所有物品重新试一遍。这意味着 dp[j] 可能先由 A 转移、也可能先由 B 转移，[A,B] 和 [B,A] 会被分别计数。→ 计顺序 = 排列。

记忆口诀：「求组合，物品在外；求排列，容量在外。」

对应题目：

零钱兑换 II（组合数）→ 物品在外、正序
组合总和 Ⅳ（其实求的是排列数）→ 容量在外
完全背包三种目标汇总
#### 🔑 记忆口诀
> **“完全背包可无限，内层循环顺着遍。”**
> (因为正序时，`dp[j-w]` 可能已经包含了一个当前物品，再加一个就是两个，符合“无限取”的逻辑)

### 🧠 进阶：关于“排列”与“组合”的陷阱

如果你遇到的问题是求**方案数**（例如：凑成金额的方法有多少种？），遍历顺序不仅影响能否重复选，还影响**顺序是否重要**。

| 问题类型 | 含义 | 嵌套顺序 | 例子 |
| :--- | :--- | :--- | :--- |
| **组合数** (Combination) | `{1, 2}` 和 `{2, 1}` 算同一种 | **外层物品，内层容量** | 零钱兑换 II (LeetCode 518) |
| **排列数** (Permutation) | `{1, 2}` 和 `{2, 1}` 算两种 | **外层容量，内层物品** | 组合总和 IV (LeetCode 377) |

#### 组合数模板 (先物后包)
```javascript
// 此时物品顺序固定，不会出现 {2, 1} 这种情况，因为 2 在 1 后面处理
const dp = new Array(capacity + 1).fill(0);
dp[0] = 1;

for (let i = 0; i < weights.length; i++) {       // 外层：物品
    const w = weights[i];
    for (let j = w; j <= capacity; j++) {        // 内层：容量 (完全背包正序)
        dp[j] += dp[j - w];
    }
}
```

#### 排列数模板 (先包后物)
```javascript
// 此时对于每个容量 j，都尝试所有物品作为“最后一步”，所以 {1, 2} 和 {2, 1} 都会被统计
const dp = new Array(capacity + 1).fill(0);
dp[0] = 1;

for (let j = 1; j <= capacity; j++) {            // 外层：容量
    for (let i = 0; i < weights.length; i++) {   // 内层：物品
        const w = weights[i];
        if (j >= w) {
            dp[j] += dp[j - w];
        }
    }
}
```

### 📝 总结：做题时的决策树

拿到一个背包问题，按以下步骤思考：

1.  **物品能选几次？**
    *   只能选 1 次 $\rightarrow$ **01 背包** $\rightarrow$ 内层**倒序**。
    *   能选无限次 $\rightarrow$ **完全背包** $\rightarrow$ 内层**正序**。

2.  **求什么？**
    *   求最大/最小价值 $\rightarrow$ `Math.max` / `Math.min` 转移。
    *   求方案数 $\rightarrow$ `+=` 累加。
        *   如果不分顺序 (组合) $\rightarrow$ **先物后包**。
        *   如果分顺序 (排列) $\rightarrow$ **先包后物**。

3.  **初始化细节**
    *   求最大值：`dp` 全 0 (若要求恰好装满且不可达，则除 `dp[0]` 外全 `-Infinity`)。
    *   求最小值：`dp` 全 `Infinity`，`dp[0] = 0`。
    *   求方案数：`dp` 全 0，`dp[0] = 1` (表示容量为 0 有一种方法：什么都不选)。
