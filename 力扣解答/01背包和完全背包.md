### 🚀 核心对比表

<font color="#9B59B6">重点：两层 for 循环我们都按照“外物品重量、内背包容量”顺序。完全背包必须从前往后遍历，01 背包必须从后往前遍历。</font>

`dp[j]` 表示 **背包容量为 j 时，可以获得的最大价值**


| 特性         | **01 背包** (每件物品选 1 次)             | **完全背包** (每件物品选无限次)               |
| :--------- | :-------------------------------- | :-------------------------------- |
| **物品限制**   | 只能选 0 或 1 次                       | 可以选 0, 1, 2, ... k 次              |
| **二维数组遍历** | 顺序随意 (通常先物后包)                     | 顺序随意 (通常先物后包)                     |
| **一维数组遍历** | **容量必须倒序** ($W \to w_i$)          | **容量必须正序** ($w_i \to W$)          |
| **状态转移方程** | `dp[j] = max(dp[j], dp[j-w] + v)` | `dp[j] = max(dp[j], dp[j-w] + v)` |
| **底层逻辑**   | 依赖**上一轮**的状态 (防止重复)               | 依赖**本轮已更新**的状态 (允许重复)             |
| **典型应用**   | 偷窃问题、分割等和子集                       | 零钱兑换、爬楼梯、组合总和                     |
|            |                                   |                                   |

### 📦 模板一：01 背包 (One-Dimensional DP)

**场景**：有 $N$ 个物品，每个物品只有一个，背包容量为 $W$，求最大价值/是否可行/方案数。

#### 💻 代码模板 (JavaScript)

```javascript
/**
 * @param {number[]} weights - 物品重量数组
 * @param {number[]} values - 物品价值数组
 * @param {number} capacity - 背包容量
 * @return {number} - 最大价值
 */
function knapsack01(weights, values, capacity) {
    const n = weights.length;
    
    // 初始化 dp 数组
    // 求最大值：初始化为 0
    // 求是否装满/方案数：通常 dp[0]=1, 其他=0
    const dp = new Array(capacity + 1).fill(0);

    // 1. 外层遍历物品
    for (let i = 0; i < n; i++) {
        const w = weights[i];
        const v = values[i];

        // 2. 内层遍历容量 -> 【关键：倒序！】
        // 从 capacity 遍历到 w，保证 dp[j-w] 是上一轮的数据
        // 也就是 j 依赖的是 i-1 时刻的状态，避免同一个物品被加两次
        for (let j = capacity; j >= w; j--) {// 从 capacity 遍历到 w
            dp[j] = Math.max(dp[j], dp[j - w] + v);
        }
    }

    return dp[capacity];
}
```

#### 🔑 记忆口诀
> **“01 背包怕重复，内层循环倒着走。”**
> (因为正序会导致 `dp[j-w]` 已经被当前物品更新过，从而选了两次)

### 🔄 模板二：完全背包 (Complete Knapsack)

**场景**：有 $N$ 种物品，每种物品无限个，背包容量为 $W$，求最大价值/最小数量/方案数。

#### 💻 代码模板 (JavaScript)

```javascript
/**
 * @param {number[]} weights - 物品重量数组
 * @param {number[]} values - 物品价值数组
 * @param {number} capacity - 背包容量
 * @return {number} - 最大价值
 */
function knapsackComplete(weights, values, capacity) {
    const n = weights.length;
    
    // 初始化
    // 求最大值：初始化为 0
    // 求最小数量：初始化为 Infinity, dp[0]=0
    const dp = new Array(capacity + 1).fill(0);
    
    // 如果是求最小值，上面那行改为: 
    // const dp = new Array(capacity + 1).fill(Infinity);
    // dp[0] = 0;

    // 1. 外层遍历物品
    for (let i = 0; i < n; i++) {
        const w = weights[i];
        const v = values[i];

        // 2. 内层遍历容量 -> 【关键：正序！】
        // 从 w 遍历到 capacity，允许利用本轮刚更新过的 dp[j-w]
        // 也就是 j 依赖的是 i 时刻（当前）的状态，符合“无限取”的逻辑
        for (let j = w; j <= capacity; j++) {
            dp[j] = Math.max(dp[j], dp[j - w] + v);
            
            // 如果是最小值问题:
            // if (dp[j - w] !== Infinity) {
            //     dp[j] = Math.min(dp[j], dp[j - w] + v);
            // }
        }
    }

    return dp[capacity];
}
```

#### 🔑 记忆口诀
> **“完全背包可无限，内层循环顺着遍。”**
> (因为正序时，`dp[j-w]` 可能已经包含了一个当前物品，再加一个就是两个，符合“无限取”的逻辑)

### 🧠 进阶：关于“排列”与“组合”的陷阱

如果你遇到的问题是求**方案数**（例如：凑成金额的方法有多少种？），遍历顺序不仅影响能否重复选，还影响**顺序是否重要**。

| 问题类型 | 含义 | 嵌套顺序 | 例子 |
| :--- | :--- | :--- | :--- |
| **组合数** (Combination) | `{1, 2}` 和 `{2, 1}` 算同一种 | **外层物品，内层容量** | 零钱兑换 II (LeetCode 518) |
| **排列数** (Permutation) | `{1, 2}` 和 `{2, 1}` 算两种 | **外层容量，内层物品** | 组合总和 IV (LeetCode 377) |

#### 组合数模板 (先物后包)
```javascript
// 此时物品顺序固定，不会出现 {2, 1} 这种情况，因为 2 在 1 后面处理
const dp = new Array(capacity + 1).fill(0);
dp[0] = 1;

for (let i = 0; i < weights.length; i++) {       // 外层：物品
    const w = weights[i];
    for (let j = w; j <= capacity; j++) {        // 内层：容量 (完全背包正序)
        dp[j] += dp[j - w];
    }
}
```

#### 排列数模板 (先包后物)
```javascript
// 此时对于每个容量 j，都尝试所有物品作为“最后一步”，所以 {1, 2} 和 {2, 1} 都会被统计
const dp = new Array(capacity + 1).fill(0);
dp[0] = 1;

for (let j = 1; j <= capacity; j++) {            // 外层：容量
    for (let i = 0; i < weights.length; i++) {   // 内层：物品
        const w = weights[i];
        if (j >= w) {
            dp[j] += dp[j - w];
        }
    }
}
```

### 📝 总结：做题时的决策树

拿到一个背包问题，按以下步骤思考：

1.  **物品能选几次？**
    *   只能选 1 次 $\rightarrow$ **01 背包** $\rightarrow$ 内层**倒序**。
    *   能选无限次 $\rightarrow$ **完全背包** $\rightarrow$ 内层**正序**。

2.  **求什么？**
    *   求最大/最小价值 $\rightarrow$ `Math.max` / `Math.min` 转移。
    *   求方案数 $\rightarrow$ `+=` 累加。
        *   如果不分顺序 (组合) $\rightarrow$ **先物后包**。
        *   如果分顺序 (排列) $\rightarrow$ **先包后物**。

3.  **初始化细节**
    *   求最大值：`dp` 全 0 (若要求恰好装满且不可达，则除 `dp[0]` 外全 `-Infinity`)。
    *   求最小值：`dp` 全 `Infinity`，`dp[0] = 0`。
    *   求方案数：`dp` 全 0，`dp[0] = 1` (表示容量为 0 有一种方法：什么都不选)。
