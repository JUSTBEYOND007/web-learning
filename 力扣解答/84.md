```\import java.util.ArrayDeque;

import java.util.Arrays;

import java.util.Stack;

  

class Solution {

    public int largestRectangleArea(int[] heights) {

        int num1[]=new int[heights.length];
		//左右边界我们是不取的！ 是不包含的！
        Arrays.fill(num1,heights.length);//右边界 初始化为length
		//标记每个柱子右侧第一个比它矮的柱子位置。如果某个柱子右侧没有更矮的柱子（即它右边的所有柱子都更高或相等），则将右边界设为数组的末尾（heights.length）。
        int num2[]=new int[heights.length];

        Arrays.fill(num2,-1);//左边界  我们初始化为-1
//标记每个柱子左侧第一个比它矮的柱子位置。如果某个柱子左侧没有更矮的柱子（即它左边的所有柱子都更高或相等），则将左边界设为 `-1`。
        ArrayDeque<Integer> stack=new ArrayDeque<>();

        for (int i = 0; i < heights.length; i++) {

            while (!stack.isEmpty()&&heights[stack.peek()]>heights[i]){

                int idx=stack.peek();

                stack.pop();

                num1[idx]=i;

            }//如果栈中有有更大的 记为坐标idx  该位置的有边界即为 num1[idx]=i; 
            //是while 可能栈中有多个符合 栈中是递增的

            if(!stack.isEmpty()){

                num2[i]=stack.peek();//说明小 即为左边界

              }

            stack.push(i);//最后存入 

        }

        int res=0;

        for (int j = 0; j < heights.length; j++) {

            int area=(num1[j]-num2[j]-1)*heights[j];//面积计算

            res=Math.max(res,area);

        }

        return  res;

    }

}
```


初始化来存储 默认值
1. **左边界 `num2[i]`** 表示的是**左侧第一个比当前柱子矮的柱子位置**，但矩形的左边缘是从当前柱子的左邻开始的（即 `num2[i] + 1`）。
    
2. **右边界 `num1[i]`** 表示的是**右侧第一个比当前柱子矮的柱子位置**，但矩形的右边缘是到当前柱子的右邻结束的（即 `num1[i] - 1`）。


总结：初始化值的选择原则
问题导向：根据问题的具体需求确定存储值（如边界标记、距离、状态等）。
简化逻辑：使用特殊值（如 -1、MAX_VALUE）避免复杂的条件判断。
一致性：确保初始化值在所有边界情况下都能正确工作。
语义清晰：选择有明确含义的值（如 false 表示未访问，-1 表示不存在）。
