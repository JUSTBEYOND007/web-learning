因为`s` 和 `p` 仅包含小写字母  我们可以通过26位长度的数组来记录对应字母出现的情况（本质是map 但是这里数组 ）     通过toString()方法来判断对应字母存值是否一样 来判断是否为异位词

我们使用map来保存p的toString() 方法 后对应的唯一的code编码
用cur来记录当前滑动窗口的 toString() 方法 后对应的唯一的code编码  判断是否相等 即可判断

因为字符串 p 的异位词的长度一定与字符串 p 的长度相同，所以我们可以在字符串 s 中构造一个长度为与字符串 p 的长度相同的滑动窗口！！！，并在滑动中维护窗口中每种字母的数量



charCodeAt() 是 JavaScript 中处理字符串时非常常用的一个方法。它的主要作用是**获取字符串中指定位置字符的 Unicode 编码（整数值）**
charCodeAt() 不填参数 默认是0  即方法前面我们的字符

```js
var findAnagrams = function(s, p) {

    const map=new Array(26).fill(0)

    const cur=new Array(26).fill(0)

    const res=[]

    for(let i=0;i<p.length;i++){

        ++map[p.charAt(i).charCodeAt()-'a'.charCodeAt()]

        ++cur[s.charAt(i).charCodeAt()-'a'.charCodeAt()]

    }

    if(cur.toString()===map.toString()){ //String 基本类型 比较的是值

        res.push(0)

    }

    for(let i=p.length;i<s.length;i++){

        --cur[s.charAt(i-p.length).charCodeAt()-'a'.charCodeAt()]

        ++cur[s.charAt(i).charCodeAt()-'a'.charCodeAt()]

        if(cur.toString()===map.toString()){

         res.push(i-p.length+1)

    }

    }

    return res

};
```


#### 2. 数组 (Array) 方案的优点是什么？

针对这道题（只有 'a'-'z' 26个字母），**数组方案是完胜 Map 的**。

#### (1) 速度更快 (Performance)

- **数组 (Array)**：访问 arr[0] 或 arr[25] 是**直接内存寻址**，时间复杂度是严格的 
    
    ```
    O(1)O(1)
    ```
    
    。计算机处理整数索引非常快。
    
- **哈希表 (Map)**：访问 map.get('a') 需要先对字符串 'a' 进行哈希计算，解决哈希冲突，然后再查找内存。虽然理论上也是 
    
    ```
    O(1)O(1)
    ```
    
    ，但实际常数时间比数组慢得多。
    

#### (2) 比较更简单高效

- **你的数组方案**：你用了 toString()，这很聪明。"1,0,2..." === "1,0,2..."。虽然字符串转换有开销，但对于只有 26 个数字的短数组，速度是可以接受的。
    
- **Map 方案**：必须像上面代码那样写循环去对比每一个 key。
    

#### (3) 空间开销更小

- **数组**：只需要开辟一段连续的内存存 26 个整数。
    
- **Map**：需要存储 Key（字符）、Value（数字）、指针等额外结构信息，占用内存更多。
