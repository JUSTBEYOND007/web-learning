“字母异位词 组合在一起”就是将所含字母数量和种类相同但是 顺序不同 eg:ate eat
字母异位词 组合在一起 组合到一起的方法 我们可以使用 <font color="#9B59B6">字母排序 来找到字母异位词</font>

<font color="#9B59B6">array.push()的返回值是 **添加元素后数组的新长度（length）** 而不是新的数组 请注意</font>

字符串排序我们先转为数组再排序再转为字符串
我们用map的value来存储对应的ele

```
var groupAnagrams = function(strs) {

    const map=new Map()

    for(let ele of strs){
		// 1. 将字符串转为数组： "eat" -> ['e', 'a', 't']
        let array =Array.from(ele)
		// 2. 字母排序： ['e', 'a', 't'] -> ['a', 'e', 't']
        let sortArray= array.sort()//排序
		// 3. 转回字符串作为 Map 的唯一 Key： ['a', 'e', 't'] -> "a,e,t"
        let key=sortArray.toString()//
		
		// 4. 从 Map 中获取该 Key 对应的分组列表，如果不存在则新建空数组
        if(map.has(key)){

            const list=map.get(key)

            list.push(ele)

            map.set(key,list)

        }

        else map.set(key,new Array(ele))

    }
	//`map.values()` 拿到了所有的分组，但它返回的是一个**迭代器**，而不是标准的数组。
    return Array.from(map.values())

};
```
