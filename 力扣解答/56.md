手动写算法 就是用一个一维数轴 来处理即可

代码我们先排序 从左向右处理
获取最后一个元组的左右值 
和当前值比较 
一共三种情况

如果当前区间的左端点在数组 res中最后一个区间的右端点之后，那么它们不会重合，我们可以直接将这个区间加入数组 res 的末尾；

否则，它们重合，判断有边界 如果当前区间的右端点在数组 res中最后一个区间的右端点左边 则是包括 我们跳过
如果当前区间的右端点在数组 res中最后一个区间的右端点右边 则修改res的右端点为当前区间的右端点

即我们需要用当前区间的右端点更新数组 res中最后一个区间的右端点，将其置为二者的较大值。

```js
var merge = function(intervals) {
	
	//`a` 和 `b` **就是 `intervals` 数组中的元素。
    intervals.sort((a,b)=>{return a[0]-b[0]})//注意我们必须写排序规则 

    const res=[]

    res.push(intervals[0])

    let l=intervals[0][0],r=intervals[0][1]

    for(let i=1;i<intervals.length;i++){

        if(r<intervals[i][0]){

            res.push(intervals[i])

        }else {

            let cur=res[res.length-1]

            cur[1]=Math.max(cur[1],intervals[i][1])

        }

        let cur=res[res.length-1]

        l=cur[0]

        r=cur[1]

    }

    return res

};
```
