当前位置水量=min(左边最高,右边最高)−当前高度
所以一般思路就是找到每个位置的左侧最高值 和右侧最高值 记录下来 然后取小值 和当前高度相减
我们可以用两个数组来记录当前位置左右最大值 时间复杂度O(n)
我们可以利用双指针来使得时间复杂度变为O（n）

- **lmax**：表示数组从 **下标 0 到下标 l** 这一段区域内，最高的柱子。
    
    - 这对 l 来说，是**百分之百准确**的“左边最高墙”。
        此时我们可以确定l位置的min(左边最高,右边最高) 因为右侧最大值会是大于等于rmax的 所以我们可以确定该位置的雨水
- **rmax**：表示数组从 **下标 r 到下标 n-1** 这一段区域内，最高的柱子。
    
    - 这对 r 来说，是**百分之百准确**的“右边最高墙”。

#### Q1: 为什么 lmax 和 rmax 的更新要包含当前位置？

即代码中先执行 lmax = max(lmax, height[l])。

- **数学保证**：这保证了 lmax >= height[l]，所以 lmax - height[l] 永远 
    
    ```
    ≥0≥0
    ```
    
    。不会出现负数水量。
    
- **物理含义**：
    
    - 如果 height[l] 很高，更新后 lmax == height[l]，相减得 0。说明这个位置是**墙壁/山峰**，存不住水。
        
    - 如果 height[l] 很矮，更新后 lmax 没变（保持之前的高值），相减得正数。说明这个位置是**坑底**，可以存水。



```
//代码比较简短
var trap = function(height) {

    let res=0,l=0,r=height.length-1

    let lmax=0,rmax=0

    while(l<r){//小于号即可 因为最后l=r时是最高点 不会存储雨水
		//// 1. 更新左右两侧目前遍历到的最高值（因为lmax、rmax都是包含当前位置） 
        lmax=lmax<height[l]?height[l]:lmax

        rmax=rmax<height[r]?height[r]:rmax

        if(lmax<rmax){//此时我们可以确定l位置的min(左边最高,右边最高) 因为右侧最大值会是大于等于rmax的 所以我们可以确定该位置的雨水

            res+=lmax-height[l]

            l++

        }else{

            res+=rmax-height[r]

            r--

        }

    }

    return res

};

```
