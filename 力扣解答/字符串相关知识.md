JavaScript 中的字符串（String）是编程中最常用、最重要的数据类型之一。为了给你一个全面、深度的知识体系，我将从**基础定义、核心特性、常用方法、ES6+ 新特性、编码原理以及高级应用**这几个维度进行梳理。

---

### 1. 基础定义与创建

在 JS 中，字符串是**原始数据类型（Primitive Type）**，用于表示文本数据。

#### 1.1 创建方式
有三种定义字符串的符号：
1.  **单引号**：`'Hello'`
2.  **双引号**：`"World"`
3.  **反引号（模板字符串）**：`` `Hello World` `` (ES6)

#### 1.2 字面量 vs 构造函数
```javascript
const str1 = "hello"; // 推荐：字面量（原始类型 typeof string）
const str2 = new String("hello"); // 不推荐：对象（引用类型 typeof object）

console.log(str1 === str2); // false
console.log(str1 == str2);  // true
```
*注意：尽量不要使用 `new String()`，因为它会创建对象，导致类型判断混淆和性能损耗。*

---

### 2. 核心特性：不可变性 (Immutability)

**这是 JS 字符串最重要的特性。**
字符串一旦创建，就无法在原地修改。所有看似“修改”字符串的方法，实际上都是**返回了一个新的字符串**。

```javascript
let str = "Hello";
str[0] = "h"; // 无效！在严格模式下会报错
console.log(str); // 依然是 "Hello"

let newStr = str.toUpperCase(); // 返回新字符串
console.log(str);    // "Hello" (原字符串没变)
console.log(newStr); // "HELLO"
```

### 3. 常用属性与基本操作

#### 3.1 长度
*   `str.length`: 返回字符个数。

#### 3.2 访问字符
*   `str[index]`: 现代浏览器支持（推荐）。
*   `str.charAt(index)`: 兼容老旧浏览器。

---

### 4. 字符串操作方法大全 (API)

为了方便记忆，我们可以将方法分类：

#### 4.1 查找与检测
*   **`indexOf(subStr, index)`**: 从前往后找，返回索引，找不到返回 `-1`。
*   **`lastIndexOf(subStr, index)`**: 从后往前找。
*   **`includes(subStr)`**: (ES6) 返回布尔值，判断是否包含。
*   **`startsWith(subStr)`**: (ES6) 是否以某字符开头。
*   **`endsWith(subStr)`**: (ES6) 是否以某字符结尾。
*   **`search(regexp)`**: 支持正则查找索引。

#### 4.2 截取与切片 (重点区分)
这三个方法很像，但有细微差别：

1.  **`slice(start, end)`** (**推荐**):
    *   含头不含尾。
    *   支持负数（表示倒数第几个）。
2.  **`substring(start, end)`**:
    *   含头不含尾。
    *   不支持负数（负数会被当做 0）。
    *   会自动交换 `start` 和 `end` 的大小位置。
3.  **`substr(start, length)`**:
    *   第二个参数是**长度**。
    *   *注：已被废弃（虽然浏览器还支持，但标准不推荐使用）。*

```javascript
let s = "JavaScript";
s.slice(0, 4);  // "Java"
s.slice(-6);    // "Script"
```

#### 4.3 转换与修改 (返回新字符串)
*   **`toLowerCase()` / `toUpperCase()`**: 大小写转换。
*   **`trim()`**: 去除首尾空格。
*   **`trimStart()` / `trimEnd()`**: 去除开头/结尾空格。
*   **`replace(search, replacement)`**: 替换第一个匹配项（支持正则）。
*   **`replaceAll(search, replacement)`**: (ES2021) 替换所有匹配项。
*   **`concat(str2, ...)`**: 连接字符串（通常用 `+` 或模板字符串代替）。
*   **`repeat(count)`**: 重复字符串 n 次。
*   **`padStart(len, pad)` / `padEnd(len, pad)`**: 字符串补全（常用于时间格式化，如 `09:00`）。

#### 4.4 分割
*   **`split(separator, limit)`**: 将字符串拆分为数组。
    *   `"a,b,c".split(",")` -> `["a", "b", "c"]`
    *   `"hello".split("")` -> `["h", "e", "l", "l", "o"]`

### 5. ES6+ 模板字符串 (Template Literals)

这是现代 JS 开发的标配，功能强大：

1.  **多行字符串**:
    ```javascript
    const html = `
      <div>
        <h1>Title</h1>
      </div>
    `;
    ```
2.  **变量插值**:
    ```javascript
    const name = "Alice";
    const greeting = `Hello, ${name}!`;
    ```
3.  **标签模板 (Tagged Templates)** (高级):
    允许你用函数解析模板字符串，常用于防止 XSS 攻击或国际化处理。
    ```javascript
    function tag(strings, ...values) {
        // 自定义处理逻辑
    }
    tag`Hello ${name}`;
    ```

### 6. 字符编码与 Unicode (深水区)

JavaScript 的字符串内部使用 **UTF-16** 编码。

#### 6.1 带来的问题
大多数常用字符（如英文字母、汉字）占 2 个字节（1个代码单元）。但生僻字或 Emoji 表情（如 𠮷, 😊）占 4 个字节（2个代码单元，即**代理对**）。

#### 6.2 经典坑与解决方案
*   **长度误判**:
    ```javascript
    "😊".length; // 2 (因为它由两个 UTF-16 单元组成)
    ```
*   **迭代乱码**:
    传统的 `for` 循环会把 Emoji 拆成两半乱码。
    **解决**: 使用 `for...of` 循环，它是 Unicode 感知的。
    ```javascript
    for (let char of "😊") { console.log(char); } // 正确输出 😊
    ```
*   **获取码点**:
    *   `charCodeAt(index)`: 返回 UTF-16 单元编码（0-65535）。
    *   `codePointAt(index)`: (ES6) 能正确返回 4 字节字符的完整 Unicode 码点。
*   **从码点创建**:
    *   `String.fromCharCode(num)`
    *   `String.fromCodePoint(num)` (ES6，支持高位字符)

### 7. 字符串比较与排序

*   **`==` / `===`**: 比较值（引用类型比较地址，但字符串是原始类型，比较的是内容）。
*   **`localeCompare()`**:
    用于本地化比较，常用于中文拼音排序。
    ```javascript
    let arr = ['张三', '李四', '王五'];
    arr.sort((a, b) => a.localeCompare(b, 'zh-Hans-CN')); 
    // 按拼音排序
    ```

---

### 8. 类型转换

#### 8.1 转为字符串
*   `String(value)`: 推荐，安全，能处理 null/undefined。
*   `value.toString()`: 如果 value 是 null/undefined 会报错。
*   `value + ""`: 隐式转换（这也是一种常用技巧）。

#### 8.2 字符串转数字
*   `Number(str)`: 严格转换，有非数字字符返回 NaN。
*   `parseInt(str, radix)` / `parseFloat(str)`: 解析转换，允许后面跟着非数字字符（如 `"100px"` -> `100`）。
*   `+str`: 一元加号，等同于 `Number(str)`。

---

### 9. 正则表达式配合

字符串经常结合正则使用，涉及四个方法：
1.  `str.match(regexp)`: 获取匹配结果数组。
2.  `str.matchAll(regexp)`: (ES2020) 返回迭代器，获取所有组匹配详情。
3.  `str.search(regexp)`: 返回索引。
4.  `str.replace(regexp, newSubStr)`。

### 总结：思维导图式记忆

1.  **本质**: 原始类型、不可变、UTF-16。
2.  **创建**: 字面量、模板字符串 `` `...` ``。
3.  **增**: `concat`, `padEnd`, `repeat`。
4.  **删/改** (返回新串): `slice`, `trim`, `replace`, `toUpperCase`。
5.  **查**: `indexOf`, `includes`, `startsWith`。
6.  **切**: `split` (转数组)。
7.  **难点**: Emoji/生僻字的 4 字节处理 (`codePointAt`, `for...of`)。
