这是一个非常经典的数据结构与算法问题。代码是<font color="#9B59B6">递归</font> 方式。

二叉树的深度优先遍历（DFS）主要分为三种：**前序（Preorder）**、**中序（Inorder）**、**后序（Postorder）**。

核心区别在于 **“什么时候处理（打印/存储）当前根节点的值”**。

---

### 第一部分：三种遍历的思路逻辑

假设我们要遍历当前节点 `root`：

1.  **前序遍历 (Pre-order)**: `Root -> Left -> Right`
    *   **思路**：我先拿到刚才那个节点的值（办事），然后再去左子树，最后去右子树。
    *   **口诀**：**中**、左、右。
    *   **代码位置**：`res.push` 放在两个递归调用**之前**。

2.  **中序遍历 (In-order)**: `Left -> Root -> Right`
    *   **思路**：我先一路跑到最左边，没路了再处理当前节点，最后去右子树。
    *   **口诀**：左、**中**、右。（这也是二叉搜索树 BST 输出有序数组的方式）。
    *   **代码位置**：`res.push` 放在两个递归调用**中间**（即你提供的示例）。

3.  **后序遍历 (Post-order)**: `Left -> Right -> Root`
    *   **思路**：先把左右子树的事情都做完了，最后才处理当前节点（汇报总结）。
    *   **口诀**：左、右、**中**。
    *   **代码位置**：`res.push` 放在两个递归调用**之后**。

---

### 第二部分：JS 代码实现（递归版 & 迭代版）

递归版最简单，利用系统调用栈；迭代版需要我们手动维护一个栈（Stack）。

#### 1. 前序遍历 (Preorder)

**递归版 (Recursive):**
```javascript
var preorderTraversal = function(root) {
    const res = [];
    function dfs(node) {
        if (!node) return;
        res.push(node.val); // 1. 先访问根
        dfs(node.left);     // 2. 再去左
        dfs(node.right);    // 3. 最后去右
    }
    dfs(root);
    return res;
};
```


#### 2. 中序遍历 (Inorder)

**递归版 (Recursive):**
```javascript
var inorderTraversal = function(root) {
    const res = [];
    function dfs(node) {
        if (!node) return;
        dfs(node.left);     // 1. 先去左
        res.push(node.val); // 2. 再访问根
        dfs(node.right);    // 3. 最后去右
    }
    dfs(root);
    return res;
};
```
#### 3. 后序遍历 (Postorder)

**递归版 (Recursive):**
```javascript
var postorderTraversal = function(root) {
    const res = [];
    function dfs(node) {
        if (!node) return;
        dfs(node.left);     // 1. 先去左
        dfs(node.right);    // 2. 再去右
        res.push(node.val); // 3. 最后访问根
    }
    dfs(root);
    return res;
};
```

### 第三部分：JS 树遍历总结 (Cheat Sheet)

做树的遍历题目，建议建立以下知识体系：

#### 1. 核心分类
| 遍历方式           | 顺序 (Left/Right/Root)  | 应用场景                         |
| :------------- | :-------------------- | :--------------------------- |
| **前序 (Pre)**   | Root -> Left -> Right | 复制树、打印目录结构、前缀表达式             |
| **中序 (In)**    | Left -> Root -> Right | **二叉搜索树(BST)转有序数组**          |
| **后序 (Post)**  | Left -> Right -> Root | **删除树(先删子再删父)**、计算目录大小、后缀表达式 |
| **层序 (Level)** | 逐层向下                  | 寻找最短路径(BFS)、按层打印             |


**DFS = Depth-First Search（深度优先搜索）**

- 思路：沿着一条路径尽可能往下走到叶子节点，再回溯到上层节点
    
- 树结构中就是“尽量深入子节点再回退”
    
- 适用：树、图

## 二、在树上的 DFS 形式

在 **二叉树** 中，DFS 常用三种方式（都是“深度优先”）：

|类型|遍历顺序|
|---|---|
|**先序** (Preorder)|根 → 左 → 右|
|**中序** (Inorder)|左 → 根 → 右|
|**后序** (Postorder)|左 → 右 → 根|

> 所以在树上，先序、中序、后序都是 **DFS 的具体实现方式**。

#### 3. 广度优先遍历 (BFS/层序遍历)
除了 DFS（前中后），树的遍历必考 BFS。

```javascript
var levelOrder = function(root) {
    if (!root) return [];
    const res = [];
    const queue = [root]; // 使用队列 (Queue) 而不是栈
    
    while (queue.length>0) {//是>0 而不是>=0
        const levelSize = queue.length; // 记录当前层有多少个节点
        const currentLevel = [];//用来保存当前层的节点 
        
        for (let i = 0; i < levelSize; i++) {//重要 每次遍历一层的节点
            const node = queue.shift(); // 是用shift弹出队首 而不是pop先进先出
            currentLevel.push(node.val);
            if (node.left) queue.push(node.left);//存在才放入
            if (node.right) queue.push(node.right);
        }
        res.push(currentLevel);///res每个元素保存的是每层的一维数组[1, 2, 3, 4, 5]
    }
    return res;
};
```

currentLevel这个变量会在下一次循环中被重新创建，但 `res` 中存的是 `layNode` 当时对应的那个数组对象的引用，它不会被销毁。
### 总结
*   **递归**：写法最简单，核心看 `res.push` 在哪一行。
*   **迭代**：**前序**用简单栈；**中序**用指针+栈；**后序**用双栈（或倒序法）。
*   **BFS**：用**队列** (`queue`)。
