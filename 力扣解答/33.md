新的理解
一句话理解：
哪边有序，就拿 target 跟这边的首尾值比。如果 target 在这个范围里，就去这边找；如果不在，就去另一边找。
因为有序区间可以靠大小判断有没有可能包含 target。乱序那边不能直接这样判断。


旧的理解
有点难理解
<font color="#9B59B6">就是先判断哪半段有序 因为我们只能在有序段中判断target是否在这个部分里（因为另外部分是一部分无序的 无法用二叉排序判断）  如果不在 就在另外半段中 而每次分割 一定会有半段是有序的（如果是有序段分割 那么左右侧都是有序的  ） 从而缩小查找范围</font>

先判断if(nums[mid]\=\=\=target) return mid
然后我们判断left到mid 和mid到right那半段有序
我们通过if(nums[left]<=nums[mid]) 判断左侧半段是否有序  注意时<= 题上说了值不相等的 =号说明左半段只有一个值  然后if(target>=nums[left]&&target<nums[mid])判断是否在左半段
在有半段 我们通过(target<=nums[right]&&target>nums[mid]判断在左半段还是右半段 

需要四个判断 左半侧还是有半侧有序 target在左半段还是有半段

```js

var search = function(nums, target) {

    let left=0,right=nums.length-1

    while(left<=right){

        let mid=Math.floor((left+right)/2)

        if(nums[mid]===target) return mid

        if(nums[left]<=nums[mid]){

            if(target>=nums[left]&&target<nums[mid]){

                right=mid-1

            }else{

                left=mid+1

            }

        }else{

            if(target<=nums[right]&&target>nums[mid]){

                left=mid+1

            }else right=mid-1

        }

    }

    return -1//上述找不到 说明不存在 返回-1即可

};
```
