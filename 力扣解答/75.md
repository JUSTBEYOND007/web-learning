思路 类似于快速排序 我们查找某一个元素的插入位置的思路
我们使用双指针left right来维护0和2接下来要交换赋值的位置

这段代码维护的是三个区间：
[0, left)     全是 0
[left, i)     全是 1
[i, right]    尚未处理
(right, n)    全是 2
所以通常有：
left <= i
但 i 可能大于 left。

```js
var sortColors = function(nums) {

    let left=0

    let right=nums.length-1

    let i=0//使用i指针来遍历

    while(i<=right){//因为right会-- 所以我们满足i<=right即可

        if(nums[i]===0){

            [nums[i],nums[left]]=[nums[left],nums[i]]

            i++//这里我们可以i++ 因为left=i时含义是右移即可 left<i时 nums[left]为1
				//我们都可以安全的右移
            left++

        }else if(nums[i]===2){

            [nums[i],nums[right]]=[nums[right],nums[i]]

            right--//此时我们不应该i++因为交换是和末尾我们没有遍历过的未知元素交换
            //我们需要再次判断该位置元素如何处理
        }else i++//

    }

};
```



记录三种颜色数量再赋值  这需要两次遍历数组 第一次记录 第二次赋值  不符合题意
```js
var sortColors = function(nums) {

    let red=0

    let white=0

    let blue=0

    for (let index = 0; index < nums.length; index++) {

        if(nums[index]===0)

            red++

        else if(nums[index]===1)

            white++

        else blue++

    }

    for (let index = 0; index < nums.length; index++) {

        if(red>0){

            nums[index]=0

            red--

            continue

        }

        if(white>0){

            nums[index]=1

            white--

            continue

        }      

        else {

            nums[index]=2

            blue--

        }

    }

};
```
