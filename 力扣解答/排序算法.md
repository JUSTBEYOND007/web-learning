### 第一梯队：基础排序（简单但效率低）

这三种算法的时间复杂度通常是 $O(n^2)$，主要用于教学或数据量极小的情况。

#### 1. 冒泡排序 (Bubble Sort)
**核心思想：** 像鱼吐泡泡一样，两两比较，大的往后移，每轮循环确定一个最大值放到最后。
**JS 代码：**
```javascript
function bubbleSort(arr) {
    const len = arr.length;
    for (let i = 0; i < len - 1; i++) {
        // 优化：如果某一轮没有发生交换，说明已经排好了，直接跳出
        let swapped = false;
        for (let j = 0; j < len - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]; // 交换
                swapped = true;
            }
        }
        if (!swapped) break;
    }
    return arr;
}
```

#### 2. 选择排序 (Selection Sort)
**核心思想：** 每次从未排序区域中找到最小的元素，放到已排序区域的末尾。
**JS 代码：**
```javascript
function selectionSort(arr) {
    const len = arr.length;
    for (let i = 0; i < len - 1; i++) {
        let minIndex = i;
        for (let j = i + 1; j < len; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j; // 找到最小值的索引
            }
        }
        // 将找到的最小值交换到当前位置
        if (minIndex !== i) {
            [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
        }
    }
    return arr;
}
```

#### 3. 插入排序 (Insertion Sort)
**核心思想：** 像打扑克牌理牌一样，拿到一张牌，从后往前扫，插入到正确位置。
**JS 代码：**
```javascript
function insertionSort(arr) {
    const len = arr.length;
    for (let i = 1; i < len; i++) {
        let current = arr[i];
        let j = i - 1;
        // 如果前一个元素比当前大，就往后挪
        while (j >= 0 && arr[j] > current) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = current;
    }
    return arr;
}
```

### 第二梯队：进阶排序（面试重点）

这两种算法采用了**分治思想**，时间复杂度为 $O(n \log n)$，是实际工程中最常用的。

#### 4. 快速排序 (Quick Sort) —— **必背！**
**核心思想：** 找一个基准值（Pivot），比它小的放左边，比它大的放右边，然后递归。
**JS 代码（标准原地交换版，空间复杂度更优）：**
```javascript
function quickSort(arr, left = 0, right = arr.length - 1) {
    if (left < right) {//是if  记住条件  因为这里使用了递归
        const partitionIndex = partition(arr, left, right);
        quickSort(arr, left, partitionIndex - 1);
        quickSort(arr, partitionIndex + 1, right);
    }
    return arr;
}

function partition(arr, left, right) {
    const pivot = arr[left]; // 选取第一个作为基准
    let index = left + 1; // index指向“大于pivot区域”的边界

    for (let i = index; i <= right; i++) {
        if (arr[i] < pivot) {
            // 发现比基准小的，交换到左边，并移动边界
            [arr[i], arr[index]] = [arr[index], arr[i]];
            index++;
        }
    }
    // 最后把pivot换到中间正确的位置
    [arr[left], arr[index - 1]] = [arr[index - 1], arr[left]];
    /*
	    **`left + 1 ~ index - 1` 全部 `< pivot`**  
	**`index ~ right` 全部 `>= pivot`**
	*/
    return index - 1;//最终位置为index - 1
}
```
*(注：前端有时候为了写起来快，会写非原地版本，即用 `filter` 生成新数组，面试时如果允许可以用，但推荐上面的版本)*

#### 5. 归并排序 (Merge Sort)
**核心思想：** 先“分”到底（拆成单个元素），再“治”（两两合并有序数组）。
**JS 代码：**
```javascript
function mergeSort(arr) {
    if (arr.length < 2) return arr;

    const middle = Math.floor(arr.length / 2);
    const left = arr.slice(0, middle);
    const right = arr.slice(middle);

    return merge(mergeSort(left), mergeSort(right));
}

function merge(left, right) {
    const result = [];
    while (left.length && right.length) {
        if (left[0] <= right[0]) {
            result.push(left.shift());
        } else {
            result.push(right.shift());
        }
    }
    return result.concat(left, right);
}
```

### 面试总结与对比（Cheat Sheet）

在面试中，除了写代码，更重要的是能**对比**它们。背下这张表，面试稳过。

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 | 适用场景/备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **冒泡** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **稳定** | 数据量极小，基本有序时。 |
| **选择** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **不稳定** | 交换次数最少（但在现代CPU上并不一定快）。 |
| **插入** | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **稳定** | **数据大部分已排序时效率极高**。 |
| **快排** | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | **不稳定** | **最常用的排序**。V8 引擎 `Array.prototype.sort` 也就是用了快排的变种。 |
| **归并** | $O(n \log n)$ | $O(n \log n)$ | $O(n)$ | **稳定** | 数据量巨大、内存不够时（外部排序）；需要稳定排序时。 |

#### 面试官常见追问：

1.  **什么是“稳定性”？为什么重要？**
    *   **定义：** 如果数组中有两个元素的值相等，排序前后它们的**相对位置**保持不变，就是稳定的。
    *   **重要性：** 比如电商订单，先按“下单时间”排好序，再按“金额”排序。如果算法是稳定的，金额相同的订单依然会保持时间先后顺序；如果是不稳定的，时间顺序就乱了。

2.  **快排的最坏情况是什么？如何避免？**
    *   **最坏情况：** 当数组已经是正序或倒序，且每次选择第一个元素作为基准（Pivot）时，退化为 $O(n^2)$。
    *   **避免：** 随机选取基准值，或者取“头、中、尾”三个数的中位数作为基准。

3.  **V8 引擎的 `sort` 源码是怎么实现的？**
    *   在数据量较小（<10）时，使用**插入排序**（因为在小数据量下，插入排序常数小，比快排更快）。
    *   数据量大时，使用**快速排序**（早起版本）或 **Timsort**（现代版本，一种归并和插入的混合排序）。

#### 记忆口诀（助记）
*   **快排：** 选基准，分两边，递归干。（不稳定）
*   **归并：** 对半切，切到底，合起来。（稳定，费空间）
*   **插入：** 摸张牌，插进去，小数据最好用。
