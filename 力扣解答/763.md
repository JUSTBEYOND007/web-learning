本质就是区间划分和贪心算法（更新ight 右边界时）
思路 我们先利用map来记录字符出现的最后位置
然后我们使用left和right来记录当前分割区间（初始化时我们分别置为0，因为要尽可能分割）
我们实时更新right右区间边界
当i===rigfht 说明该区间的字符没有在该区间外的地方出现过了 是最小分割点
然后我们更新left和right 记录下一个区间
```js
var partitionLabels = function(s) {

    const map=new Map()

    const ans=[]

    for(let i=0;i<s.length;i++){

        map.set(s.charAt(i),i)

    }

    let left=0

    let right=0

    for(let i=0;i<s.length;i++){

        if(map.get(s.charAt(i))>right)

            right=map.get(s.charAt(i))

        if(i===right){

            ans.push(right-left+1)

            left=i+1//// right 不需要重置，循环中会动态更新
			
        }

    }

    return ans

};
```
