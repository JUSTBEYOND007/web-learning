我们将第一行第一列来保存这一列和这一行是否有零的情况  如果有零 我们置为零
我们使用rowZero和colZero来保存初始时首行和首列 有无零的情况
 因为第一行和第一列都是先遍历到的 所以不用担心覆盖原来值的问题
第一次遍历 整体遍历 修改首行首列 和rowZero和colZero
第二次遍历 修改（1，1）之后的矩阵值
第三次遍历 修改第一行
第四次遍历 修改第一列


差不多都是for循环重复  懂了 代码 很好写
```
/**

 * @param {number[][]} matrix

 * @return {void} Do not return anything, modify matrix in-place instead.

 */

var setZeroes = function(matrix) {

    let rows=matrix.length

    let cols=matrix[0].length

    let rowZero=1,colZero=1

    //第一次遍历

    for(let i=0;i<rows;i++){

        for(let j=0;j<cols;j++){

            if(matrix[i][j]==0){

                matrix[0][j]=matrix[i][0]=0

                if(i==0) rowZero=0

                if(j==0) colZero=0

            }

        }

    }

    //第二次遍历 从（1，1）开始

     for(let i=1;i<rows;i++){

        for(let j=1;j<cols;j++){

            if(matrix[0][j]==0||matrix[i][0]==0)

                matrix[i][j]=0

        }

    }

    //修改第一行

    if(rowZero==0){

        for(let i=0;i<cols;i++){

            matrix[0][i]=0

        }

  

    }

        //修改第一列

    if(colZero==0){

        for(let j=0;j<rows;j++){

            matrix[j][0]=0

        }

    }

};
```

**顺序问题**：为什么不先处理第一行？

- _答_：如果先处理了第一行，第一行的标记信息就全没了，后续内部矩阵就不知道根据什么来置零了。所以必须**先标记、再填内、后填外**。
