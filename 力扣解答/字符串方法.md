# 📚 JS 字符串常用方法笔记

## ⚠️ 核心原则：不可变性 (Immutability)
**永远记住**：字符串的所有方法**都不会改变原字符串**，它们都会返回一个新的字符串。

```javascript
let str = "hello";
str.toUpperCase(); 
console.log(str); // 仍然是 "hello"

// 正确做法：赋值给新变量或覆盖原变量
str = str.toUpperCase(); 
console.log(str); // "HELLO"
```

## 1. 🔍 查找与检测 (Searching & Checking)

### `includes(subStr)` [ES6]
**用途**：判断是否包含某个字符串（最常用）。
**返回**：`Boolean`
```javascript
const str = "Hello World";

console.log(str.includes("World")); // true
console.log(str.includes("java"));  // false
```

### `indexOf(subStr)`
**用途**：查找子串第一次出现的位置（索引）。
**返回**：`Index` (找不到返回 `-1`)
```javascript
const str = "hello world";

console.log(str.indexOf("o"));   // 4
console.log(str.indexOf("xyz")); // -1
// 常用技巧：if (str.indexOf('a') !== -1) { ... }
```

### `startsWith()` / `endsWith()` [ES6]
**用途**：判断是否以某字符开头或结尾。
**返回**：`Boolean`
```javascript
const file = "image.png";

console.log(file.startsWith("image")); // true
console.log(file.endsWith(".png"));    // true
```

## 2. ✂️ 截取与切片 (Slicing)

### `slice(start, end)` (⭐ 推荐使用)
**用途**：提取字符串的一部分。
**参数**：`start` (开始索引), `end` (结束索引，**含头不含尾**)。
**特点**：支持负数（代表倒数）。
```javascript
const str = "JavaScript";

// 1. 基础用法
console.log(str.slice(0, 4));  // "Java" (取索引 0,1,2,3)

// 2. 省略第二个参数（截取到最后）
console.log(str.slice(4));     // "Script"

// 3. 使用负数（从后往前数）
console.log(str.slice(-6));    // "Script" (倒数第6个字符开始到最后)
console.log(str.slice(-6, -1)); // "Scrip"
```

> **笔记**: 还有一个 `substring()` 方法，功能类似但不支持负数，建议优先使用 `slice`，记忆负担更小。

## 3. 🛠️ 修改与替换 (Modifying)

### `replace(search, newStr)`
**用途**：替换匹配的字符。
**注意**：默认只替换**第一个**匹配项（除非使用正则全局匹配）。
```javascript
const str = "I love apple, apple is good.";

// 只替换第一个
console.log(str.replace("apple", "orange")); 
// "I love orange, apple is good."

// 使用正则替换所有 (/g)
console.log(str.replace(/apple/g, "orange")); 
// "I love orange, orange is good."
```

### `replaceAll(search, newStr)` [ES2021]
**用途**：替换**所有**匹配项（无需写正则，超级好用）。
```javascript
const str = "banana";
console.log(str.replaceAll("a", "o")); // "bonono"
```

### `trim()`
**用途**：去除字符串**首尾**的空格（中间的空格不会去）。
**场景**：处理用户表单输入。
```javascript
const input = "   admin   ";
console.log(input.trim()); // "admin"

// 还有 trimStart() 和 trimEnd()
```

### `toUpperCase()` / `toLowerCase()`
**用途**：全大写 / 全小写。
**场景**：搜索时不区分大小写比较。
```javascript
const str = "Vue.js";
console.log(str.toUpperCase()); // "VUE.JS"
console.log(str.toLowerCase()); // "vue.js"
```

## 4. 🔗 转换与拆分 (Split & Join)

### `split(separator)` (⭐ 重点)
**用途**：将字符串拆分为**数组**。
```javascript
const date = "2023-10-01";
const parts = date.split("-"); 
console.log(parts); // ["2023", "10", "01"]

// 常见技巧：字符串转字符数组
const name = "Sky";
console.log(name.split("")); // ["S", "k", "y"]
```

### `concat()`
**用途**：连接字符串。
**注意**：现代开发中很少用这个，通常用 `+` 或 模板字符串。
```javascript
const a = "Hello";
const b = "World";

// 不推荐
console.log(a.concat(" ", b)); 

// 推荐 (ES6 模板字符串)
console.log(`${a} ${b}`); 
```

---

## 5. 🎨 格式化与填充 (Formatting)

### `padStart(length, char)` / `padEnd()`
**用途**：在开头或结尾补全字符直到指定长度。
**场景**：时间格式化（补0）、脱敏显示。
```javascript
// 时间补0
const hour = "9";
console.log(hour.padStart(2, "0")); // "09"

// 手机号掩码
const phone = "1234";
console.log(phone.padStart(11, "*")); // "*******1234"
```

### `repeat(count)`
**用途**：将字符串重复 N 次。
```javascript
console.log("哈".repeat(3)); // "哈哈哈"
```

## 6. 📝 简易速查表

| 目的 | 方法 | 备注 |
| :--- | :--- | :--- |
| **想知道有多少个字** | `.length` | 属性，不是方法 |
| **想截取一部分** | `.slice(start, end)` | 最推荐，支持负数 |
| **想转成数组** | `.split(separator)` | 比如按逗号切割 |
| **想查找是否存在** | `.includes(str)` | 返回 true/false |
| **想查找位置** | `.indexOf(str)` | 返回索引，-1代表没找到 |
| **想替换文字** | `.replaceAll(old, new)` | 替换所有 |
| **想去空格** | `.trim()` | 只去首尾 |
| **想转大小写** | `.toLowerCase()` | 常用 |
