代码很简单  （动态规划+贪心算法的思想）

子数组 我们通常首先想到的是双指针 但是这里有正数和负数 

一旦引入负数，单调性就被破坏了：

1. 右指针向右移动读到一个负数，和反而变小了。
    
2. 左指针向右缩减去掉一个负数，和反而变大了。
    
**这就导致了双指针无法判断“何时该缩，何时该扩”**。

- 比如数组 [1, -2, 10, -5]。
    
- 如果用双指针，当你遇到 -2 时，总和变小了，你不知道后面会不会有一个巨大的 100 把总和救回来，所以你不知道该不该移动左指针舍弃前面的部分。

我们需要定义一个状态 dp[i]。  
**dp[i] 的含义是：以第 i 个元素结尾的“最大连续子数组和”。**   即pre 
注意：必须以 i 结尾，必须包含 nums[i]。

我们只需要最大的值 即用res来保留即可 不需要数组

#### 状态转移方程（核心逻辑）

- 如果 dp[i-1]（前一个元素结尾的最大和）是 **正数**：那么加上前面的肯定比光秃秃的自己要大。
    
    - dp[i] = dp[i-1] + nums[i]  （就是前面的数累加起来是正数 那么我们就加上来 否则我们从新开始）
        
- 如果 dp[i-1] 是 **负数**（或者0）：加上前面的只会让自己变小，不如抛弃前面。
    
    - dp[i] = nums[i]

```
var maxSubArray = function(nums) {

    let pre=0,res=nums[0]

    /**

     pre 以当前遍历到的元素 nums[i] 为结尾的最大子数组和

     res 表示目前为止遍历过程中出现过的最大值”（全局最大值）

     */

    for(let i=0;i<nums.length;i++){

        if(pre>0){

            pre+=nums[i]

        }else{

            pre=nums[i]

        }

        res=Math.max(res,pre)

    }

    return res

};
```
