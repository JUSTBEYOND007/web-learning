方法：dummy节点+双指针交换
头结点会变 所以用dummyNode
我们把两个元素看作一组 node1、node2 双指针进行交换(交换有点绕 我们用node1、node2)

如果为一个或者cur.next不存在了 即后续不存在了 我们都不处理了 因为一个元素不需要处理
```
var swapPairs = function(head) {

    const dummyNode=new ListNode(-1,head)

    let cur=dummyNode

    while(cur.next&&cur.next.next){

        let node1=cur.next,node2=cur.next.next

        let tmp=node2.next

        node2.next=node1

        node1.next=tmp

        cur.next=node2

        cur=node1//cur始终指向下一个两元素组合的前面最后一个节点 即该组最后一个节点

    }

    return dummyNode.next

};
```
