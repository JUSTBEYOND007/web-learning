 滑动窗口是为了**贪心**地保留尽可能多的字符，而不是遇到错误就“掀桌子”重来。


# 滑动窗口正好满足两个条件

### (**1**) 要维持一个“连续不重复”的区间

→ 窗口 `[start, i]`

### (**2**) 要找到所有满足条件的区间里最长的

→ `maxLength = Math.max(...)`

这两个都是滑动窗口的最擅长的事情。


我们遍历求以i索引结尾的最大字串长度 res记录其中最大的
map来记录字母的最新出现索引

```js
var lengthOfLongestSubstring = function(s) {

    //滑动窗口

    const map=new Map()//map来记录遇到的字符 以及对应最新的位置

    let l=0//窗口左位置

    let res=0

    for(let i=0;i<s.length;i++){//每次遍历是为了获得当前位置结尾的无重复子串最大长度

        if(map.has(s.charAt(i))&&map.get(s.charAt(i))>=l){

            l=map.get(s.charAt(i))+1

            map.set(s.charAt(i),i)//更新索引！！！

        }else{

            map.set(s.charAt(i),i)

            res=Math.max(res,i-l+1)

        }

    }

    return res

};

```
