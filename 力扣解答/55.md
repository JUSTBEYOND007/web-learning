我们使用rightMax实时记录我们能走到最远的地方  遍历一遍数组 判断rightMax
遍历完我们判断rightMax和nums.length-1大小即可
记住遍历条件index < nums.length &&index <=rightMax  我们需要保证index不要越界
仅仅index <=rightMax rightmax这样可能会越界
导致因为循环越过了数组边界，导致 maxLength 变成了 NaN。
执行到 [2,3,1,1,4] 时：
i = 1
maxLength = Math.max(3 + 1 + 1, 3) // 5
此时已经能到达数组末尾，但循环条件是：
i < maxLength
所以循环还会继续。当 i = 5 时：
nums[5] // undefined
undefined + 5 + 1 // NaN
Math.max(NaN, 9) // NaN
最终：
NaN >= nums.length // false

一直为为fasle

```js
var canJump = function(nums) {

    let rightMax=0

    for (let index = 0;  index < nums.length &&index <=rightMax; index++) {

        rightMax=Math.max(rightMax,index+nums[index])

    }

    return rightMax>=nums.length-1

};
```
