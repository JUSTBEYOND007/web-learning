其数字都在 [1, n] 范围内（包括 1 和 n）  我们可以通过数组值作为索引来建立链表
数组思路我们通过数组对应索引下的值 和对应索引建立起链接 我们看作链表
思路就类似力扣142即可

```js
class Solution {
    public int findDuplicate(int[] nums) {
        int slow=0,fast=0;
        while (true){
            slow=nums[slow];
            fast=nums[nums[fast]];
            if (slow==fast)
                break;
        }
        fast=0;
        while (true){
            slow=nums[slow];
            fast=nums[fast];
            if(slow==fast)
                return slow;
        }
    
    }
}
```
