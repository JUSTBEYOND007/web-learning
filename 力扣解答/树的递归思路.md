代码是 ```
```JS
function dfs(){
	//1.终止条件
	//2.递归左右子树
	//3.处理当前节点  //2、3这两点顺序可变 例如中序就是递归左子树 处理当前节点 递归右子树
	//4.返回值
}

```


## 一、固定四步法（这是最重要的）



### **第 1 步：定义递归函数的“语义”**（最关键）

先在脑子里明确一句话：

> `dfs(root)` 的返回值 / 副作用 是什么？

例如：

- 翻转二叉树  
    👉 `invertTree(root)`：**返回翻转后的子树**
    
- 中序遍历  
    👉 `dfs(root)`：**把 root 子树的值加入结果**
    
- 最大深度  
    👉 `maxDepth(root)`：**返回 root 子树的最大深度**
    

⚠️ **不明确这一步，递归一定写乱**

---

### **第 2 步：写递归终止条件（base case）**

几乎 90% 的树题都是：

`if (!root) return ...`

- 返回什么，取决于你第 1 步定义的语义
    

例子：

- 返回树 → `return null`
    
- 返回数字 → `return 0`
    
- 无返回值 → `return`
    

---

### **第 3 步：递归处理左右子树**

`let left = dfs(root.left) let right = dfs(root.right)`

这一步的**心理暗示非常重要**：

> **“我不管 dfs 内部怎么实现，  
> 我只相信它已经把左右子树处理好了”**

---

### **第 4 步：处理当前节点（只做一层的事）**

根据题目，在这一层**组合 / 交换 / 计算**：

`// 利用 left 和 right // 或修改 root return ...`



写二叉树的递归算法，其实就像是在填空。无论题目多难，代码结构通常都逃不出这 **“三部曲”**。

为了让你彻底掌握这个“套路”，我把写代码的过程拆解为 **3 个固定步骤**。以后看到树的题目，直接按这个顺序去思考。

---

### 二叉树递归“三部曲”通用模版

任何递归函数，你都可以先写下这个架子：

```javascript
var solution = function(root) {
    // 步骤 1：终止条件 (Base Case)
    // 如果走到空节点了，该返回什么？
    if (!root) {
        return ...; // 比如 null, 0, true, [] 等
    }

    // 步骤 2 & 3：单层逻辑 + 递归调用
    // 这里决定了是“先办事再递归”（前序），还是“先递归再办事”（后序）
};
```

接下来，我们根据题目类型，分两种最常见的“流派”来填充这个架子。

---

### 流派一：自底向上（汇报型 / 后序遍历）
**适用场景**：父节点需要子节点的计算结果才能算出自己的结果。
**口诀**：**“左右问一遍，最后算自己”**。
**典型题目**：求树高、求节点个数、判断平衡二叉树、翻转二叉树（你的写法）。

**代码套路：**

```javascript
var func = function(root) {
    // 1. 【终止条件】：到底了怎么办？
    // 通常涉及数字的返回 0，涉及节点的返回 null
    if (!root) return 0; 

    // 2. 【递归调用】：先派人去左右两边拿结果
    // 就像你的 invertTree 代码：let left = ... let right = ...
    let leftResult = func(root.left);
    let rightResult = func(root.right);

    // 3. 【单层逻辑】：拿到左右结果后，我也要向上级汇报
    // 这里是核心处理逻辑，比如取最大值、相加、交换引用等
    let myResult = process(leftResult, rightResult); 
    
    return myResult;
};
```

**应用示例（求最大深度）：**
1.  **终止**：`if(!root) return 0`
2.  **递归**：`L = dfs(root.left)`, `R = dfs(root.right)`
3.  **逻辑**：`return Math.max(L, R) + 1`

---

### 流派二：自顶向下（传达型 / 前序遍历）
**适用场景**：父节点要把参数传下去，或者父节点先处理完，再让子节点继续处理。
**口诀**：**“自己先做事，剩下的交给左右”**。
**典型题目**：翻转二叉树（另一种写法）、路径总和（把剩下的目标值传下去）、打印树。

**代码套路：**

```javascript
var func = function(root) {
    // 1. 【终止条件】
    if (!root) return null;

    // 2. 【单层逻辑】：先处理当前节点
    // 比如：交换左右孩子、打印当前值、目标值减去当前值
    doSomething(root);

    // 3. 【递归调用】：处理完自己，再让手下去干活
    func(root.left);
    func(root.right);
    
    // 通常返回 root 自身，或者不需要返回值
    return root; 
};
```

**应用示例（翻转二叉树 - 前序版）：**
1.  **终止**：`if(!root) return null`
2.  **逻辑**：`[root.left, root.right] = [root.right, root.left]` (交换)
3.  **递归**：`invert(root.left)`, `invert(root.right)`

---

### 流派三：外挂变量（辅助函数 / 遍历型）
**适用场景**：要把树里所有满足条件的东西收集到一个数组或者变量里。
**口诀**：**“带个笔记本，走到哪记到哪”**。
**典型题目**：前/中/后序遍历、所有路径、左叶子之和。

**代码套路：**

```javascript
var traversal = function(root) {
    // 0. 【准备工作】：定义外部变量（笔记本）
    const result = [];

    // 定义递归函数
    function dfs(node) {
        // 1. 【终止条件】
        if (!node) return;

        // 2 & 3. 【逻辑与递归】：顺序决定了是前/中/后序
        // result.push(node.val); // 放在这就叫前序
        dfs(node.left);
        // result.push(node.val); // 放在这就叫中序
        dfs(node.right);
        // result.push(node.val); // 放在这就叫后序
    }

    // 启动
    dfs(root);
    return result;
};
```

---

### 终极心法：我该怎么选？

当你拿到一道新题，哪怕不知道具体怎么写，先按这个流程问自己：

1.  **Base Case 怎么写？**
    *   通常是 `if (!root) return ...`。
    *   问自己：如果是空树，深度是 0 还是 null？是 true 还是 false？

2.  **我需要子树给我结果吗？（Return Value）**
    *   **需要**（比如问高度、问是不是平衡、问子树翻转好了没）：用 **流派一（后序，自底向上）**。即 `let left = dfs(...)`。
    *   **不需要**（只是去遍历、去修改结构）：用 **流派二（前序）** 或 **流派三（外挂变量）**。

3.  **当前这一层我要干嘛？（Logic）**
    *   求深度：`Max(左, 右) + 1`。
    *   翻转：`root.left = 右边递归结果`。
    *   求和：`root.val + 左边和 + 右边和`。

**实战演练：**
假设题目是 **“判断两棵树是否相同” (Same Tree)**。

1.  **终止条件**：
    *   如果你空我也空 -> `true`。
    *   如果你空我不空（或反之） -> `false`。
2.  **需要子树结果吗？**
    *   需要。我要知道左子树是不是一样，还要知道右子树是不是一样。-> **流派一**。
3.  **当前层逻辑**：
    *   我自己节点的值必须一样，**且** 左边结果必须为 true，**且** 右边结果必须为 true。

```javascript
var isSameTree = function(p, q) {
    // 1. 终止条件
    if (!p && !q) return true; // 都空
    if (!p || !q) return false; // 一个空一个不空
    if (p.val !== q.val) return false; // 值不一样

    // 2. 递归 (问子节点)
    let leftSame = isSameTree(p.left, q.left);
    let rightSame = isSameTree(p.right, q.right);

    // 3. 逻辑汇总
    return leftSame && rightSame;
};
```

> **是否需要闭包，取决于：  
> 你是否需要在多次递归调用之间「共享状态」。**

- **需要共享状态 → 用闭包**
    
- **不需要共享状态 → 不用闭包**

什么是共享状态  
- 递归函数每一层都有自己的参数和局部变量
    
- **如果你想让所有层看到同一个东西，就得放到外面**
    
- JS/Java 里，**闭包 / 全局变量**就是实现这个共享的方式
