## 1️⃣ 回溯算法概念回顾

回溯算法（Backtracking）是一种**系统搜索问题所有可能解**的方法，通常用于组合问题、排列问题、子集问题、棋盘问题等。

基本思路是：

1. 从初始状态出发，尝试每一种可能的选择。
    
2. 每做一个选择，进入下一个决策点。
    
3. 如果发现当前路径不可能产生有效解，就**回退（撤销选择）**，尝试其他可能性。
    

回溯算法的核心特点是**尝试+撤销**，但纯暴力回溯可能会非常慢，尤其是问题规模大的时候。

---

## 2️⃣ 剪枝的概念

**剪枝（Pruning）**指的是在回溯搜索过程中，**提前排除那些不可能得到有效解的分支**，不再继续探索它们，从而减少计算量。

简单理解：

> “如果我沿着当前路径走下去，已经知道不会有答案了，那就不走了，直接回退。”

剪枝是一种**优化策略**，能让回溯算法在大规模问题下也能高效运行。

---

## 3️⃣ 剪枝的作用

- **减少搜索空间**：不再尝试无效或重复的分支。
    
- **提高效率**：降低算法时间复杂度。
    
- **避免重复计算**：特别是在有对称性或者约束条件的情况下。
    

---

## 4️⃣ 常见剪枝方法

### （1）约束条件剪枝

在选择下一步之前，先判断是否满足问题的约束条件，不满足就不继续递归。

**示例：八皇后问题**

```text
放置第i个皇后前，先判断该行、列、斜线是否已有皇后。
如果冲突，直接剪枝，不再递归。
```

### （2）目标函数剪枝

如果当前路径已经超过目标值（或无法达到目标），就停止搜索。

**示例：组合求和**

```text
在递归过程中，当前组合和 sum > target，就剪枝，不再尝试剩余元素。
```

### （3）重复状态剪枝（去重）

在有重复元素的情况下，避免生成相同的解。

**示例：子集问题**

```python
nums = [1, 2, 2]
# 在递归时，跳过同一层相同的数字，避免生成重复子集
```

### （4）贪心或启发式剪枝

结合问题特点，估计剩余最优情况，如果不可能超过已有解就剪枝。

**示例：0-1 背包问题回溯**

```text
当前背包已放入物品总价值 + 剩余物品的最大可能价值 < 当前最优解
→ 剪枝，不再尝试。
```

---

## 5️⃣ 简单示例（Python）

**组合求和问题**：从数组中选数字，求和为目标值。

```python
def backtrack(start, path, target):
    if target == 0:
        print(path)  # 找到解
        return
    for i in range(start, len(nums)):
        if nums[i] > target:   # 剪枝
            break
        backtrack(i, path + [nums[i]], target - nums[i])

nums = [2,3,6,7]
nums.sort()   # 剪枝前提：数组有序
backtrack(0, [], 7)
```

解释：

- `if nums[i] > target: break` → **剪枝**，后面的数字更大，肯定无法凑出目标和，直接停止本分支搜索。
    
- 通过排序，剪枝更加有效。
    

---

💡 总结：

- 回溯算法本质是暴力搜索。
    
- **剪枝**是减少搜索空间的策略，让回溯高效。
    
- 常用方式：约束条件、目标函数、去重、贪心估计。
    
- 有效剪枝可以让算法从指数级时间复杂度下降很多。
