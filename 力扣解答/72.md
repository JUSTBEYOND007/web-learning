这是一道感觉需要背 而且比较好背的题 如果完全理解透三种操作怎么做的 再去做有些耗时间
开背：
dp[i]/[j] 代表 word1 到 i 位置转换成 word2 到 j 位置需要最少步数
如果word1.charAt(i-1)=/=/=word2.charAt(j-1) 那么dp[i][j]=dp[i-1]/[j-1]
删除 修改 和新增三种操作正好对应
f(i,j-1)+1(将s1最后一个字符插入到s2中)，将f(i-1,j)+1（将s1最后一个字符删除）,f(i-1,j-1)+1(将s1的最后一个元素替换为s2) 
```js
dp[i-1][j-1],Math.min(dp[i-1][j],dp[i][j-1]
```
这三种操作 所以 我们求其中最小的我们加一即可

代码很简单 和前面的力扣代码很相似
```js
var minDistance = function(word1, word2) {

    const dp=Array.from({length:word1.length+1},()=>new Array(word2.length+1).fill(0))
	//对应边界的赋值 
    for (let i = 0; i <=word1.length; i++){

        dp[i][0]=i//即全删除操作

    }

    for (let i = 0; i <=word2.length; i++){

        dp[0][i]=i//即全插入操作

    }

    for (let i = 1; i <=word1.length; i++) {

        for (let j = 1; j <= word2.length; j++) {

            if(word1.charAt(i-1)===word2.charAt(j-1)){

                dp[i][j]=dp[i-1][j-1]

            }else{

                dp[i][j]=Math.min(dp[i-1][j-1],dp[i-1][j],dp[i][j-1])+1

            }

        }

    }

    return dp[word1.length][word2.length]

};
```


```java
class Solution {

    public int minDistance(String text1, String text2) {

        char[] s1 = text1.toCharArray();

        char[] s2 = text2.toCharArray();

        int dp[][] = new int[s1.length + 1][s2.length + 1];

        for (int i = 0; i <= s1.length; i++) {

            dp[i][0] = i;

        }

        for (int j = 0; j <= s2.length; j++) {

            dp[0][j] = j;

        }

        for (int i = 0; i < s1.length; i++) {

            for (int j = 0; j < s2.length; j++) {

                if (s1[i] == s2[j])

                    dp[i + 1][j + 1] = dp[i][j];

                else

                    dp[i + 1][j + 1] = Math.min(

                        Math.min(dp[i][j + 1], dp[i + 1][j]),

                        dp[i][j]

                    ) + 1;

            }

        }

        return dp[s1.length][s2.length];

    }

}
```

主要是将 插入 删除 替换 抽象为f(i,j)与f(i,j-1),f(i-1,j),f(i-1,j-1)的关系 
如果最后一个字符相等 就等于将f(i,j)=f(i-1,j-1)  注意最后一个字符不需要操作  不用加一！！！
如果最后一个字符不等 如果将是s1变成为s2那么 就是f(i,j-1)+1(将s1最后一个字符插入到s2中)，将f(i-1,j)+1（将s1最后一个字符删除）,f(i-1,j-1)+1(将s1的最后一个元素替换为s2)  三种操作情况下的最小值
