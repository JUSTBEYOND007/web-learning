## 笔记：盛最多水的容器（双指针法）

### 1. 核心思想：贪心策略与双指针

本题的关键在于理解**指针移动的逻辑**。我们使用左右双指针，分别指向数组的两端，通过不断向内收缩来寻找最大面积。

### 2. 面积公式与推导

设左指针指向的高度为 $x$，右指针指向的高度为 $y$，两指针间的距离为 $t$。

则当前面积为：

$$Area = \min(x, y) \times t$$

为什么移动短板？

假设当前 $x \leq y$（即左侧为短板）：

- **如果移动长板 ($y$)**：新的高度一定会受限于短板 $x$，因此高度 $h \leq x$。而距离 $t$ 减小为 $t-1$。
    
    - 结论：面积一定会变小，没有尝试的意义。
        
- **如果移动短板 ($x$)**：虽然距离 $t$ 减小了，但新高度**可能**会变得比 $x$ 更大。
    
    - 结论：只有移动短板，面积才**有可能**增大。
        

### 3. 算法流程

1. **初始化**：左指针 `left = 0`, 右指针 `right = n - 1`。
    
2. **循环条件**：当 `left < right` 时持续循环。
    
3. **更新最值**：计算当前面积，并与全局最大值 `res` 比较更新。
    
4. **指针移动**：比较左右指针指向的高度，**谁小就移动谁**。
    
5. **结束**：当两指针相遇，返回 `res`。
    

### 4. 代码实现 (JavaScript)

JavaScript

```
/**
 * @param {number[]} height
 * @return {number}
 */
var maxArea = function(height) {
    let res = 0;
    let left = 0;
    let right = height.length - 1;

    while (left < right) {
        // 1. 计算当前窗口的宽度与高度
        const width = right - left;
        const h = Math.min(height[left], height[right]);
        
        // 2. 更新最大面积
        res = Math.max(res, width * h);

        // 3. 贪心移动：舍弃短板，寻找潜在的长板
        if (height[left] < height[right]) {
            left++;
        } else {
            right--;
        }
    }

    return res;
};
```
