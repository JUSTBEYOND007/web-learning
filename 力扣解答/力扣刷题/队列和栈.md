### 1. `Queue<TreeNode> nodeQueue = new ArrayDeque<TreeNode>();`

- **`Queue<TreeNode>` (接口)**:
    
    - 这声明了一个变量 `nodeQueue`，它的类型是**队列（Queue）**。
        
    - `Queue` 是 Java 集合框架中的一个**接口**，它定义了一系列先进先出（FIFO - First In, First Out）的操作，比如 `offer()` (入队), `poll()` (出队), `peek()` (查看队首元素)等。
        
    - 你可以把它想象成现实生活中的排队队伍，先来的人先办完事出去。
        
- **`new ArrayDeque<TreeNode>()` (实现)**:
    
    - `ArrayDeque` 是一个**具体的类**，它实现了 `Queue` 接口。
        
    - 它底层是基于**数组**实现的，性能非常高，通常被**推荐**作为常规队列（Queue）和栈（Stack）的首选实现。

### 2. `Deque<Integer> levelList = new LinkedList<Integer>();`

- **`Deque<Integer>` (接口)**:
    
    - 这声明了一个变量 `levelList`，它的类型是**双端队列（Deque）**，全称是 Double Ended Queue。
        
    - `Deque` 也是一个接口，它继承自 `Queue` 接口。
        
    - 相比普通的 `Queue`，`Deque` 提供了更强大的功能：它**允许在队列的两端进行添加和删除元素**。
        
        - 普通队列 `Queue`：只能从**尾部**添加 (`offer`)，从**头部**移除 (`poll`)。
            
        - 双端队列 `Deque`：既可以从**尾部**添加 (`offerLast`)，也可以从**头部**添加 (`offerFirst`)；既可以从**头部**移除 (`pollFirst`)，也可以从**尾部**移除 (`pollLast`)。
            
- **`new LinkedList<Integer>()` (实现)**:
    
    - `LinkedList` 是一个**具体的类**，它既实现了 `List` 接口，也实现了 `Deque` 接口。
        
    - 由于 `LinkedList` 底层是基于**双向链表**实现的，所以在链表的头部和尾部进行添加或删除操作的效率都非常高（时间复杂度为 O(1)）。
        
    - 因此，`LinkedList` 是作为 `Deque` 的一个非常理想的实现。

    - 当从左到右遍历某一层时，你可以从**尾部添加**元素 (`levelList.offerLast(node.val)`)。
