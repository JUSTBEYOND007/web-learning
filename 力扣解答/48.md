思路正确 用变量保存 然后循环赋值 重点是循环条件和四个点我们如何表示

注意是n\*n  所以top=left bottom=right
我们用left为左边界 right为右边界 同时上下边界top=left bottom=right 所以只用两个变量即可

当left\==right的时候 只剩下一个节点  我们不需要再循环  即while(left<right)

四个角  初始被替换掉的值 我们用tmp保存

我们用fori来循环每一条边
i表示距离左边界的距离 从0到right-left  即该行（列）的倒数第二个元素
分别为maxtrix\[left]\[left+i]  maxtrix\[right-i]\[left]  maxtrix\[right]\[right-i]  maxtrix\[left+i]\[right]

```
var rotate = function(matrix) {

    let left=0,right=matrix[0].length-1

    //注意是矩阵

    while(left<right){

        for(let i=0;i<right-left;i++){

            let tmp=matrix[left][left+i]

            matrix[left][left+i]=matrix[right-i][left]

            matrix[right-i][left]=matrix[right][right-i]

            matrix[right][right-i]=matrix[left+i][right]

            matrix[left+i][right]=tmp

        }

        left++

        right--

    }

};
```
