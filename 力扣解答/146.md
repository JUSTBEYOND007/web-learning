# **一、迭代器 Iterator 是什么？**

**Iterator 是一种用于逐个遍历数据的机制。**

形式上，一个迭代器就是一个对象，它具有一个 `.next()` 方法，每次调用 `.next()`：

返回：

{ value: 数据值, done: 布尔值 }

例如：

const iterator = ['a','b','c'][Symbol.iterator]();  
  
iterator.next(); // { value: 'a', done: false }  
iterator.next(); // { value: 'b', done: false }  
iterator.next(); // { value: 'c', done: false }  
iterator.next(); // { value: undefined, done: true }

                    this.capacity=capacity

这行代码利用了迭代器（Iterator）来获取 Map 的 **第一个元素**（也就是最久未使用的）。

<font color="#007ACC">next() 用keys（）方法来返回迭代器对象 使用next（）方法 来获得第一个对象  格式固定的！为：{ value: key值, done: false } ，即value就是我们要取得第一个key值</font>
1. this.map.keys():
    
    - 返回一个 **迭代器对象 (Iterator)**。
        
    - 这个迭代器按 **插入顺序** 包含所有的 key。
        
    - 因为 Map 有序，第一个被迭代出来的就是 **头部**（最老的元素）。
        
2. .next():
    
    - 这是迭代器的方法，手动获取下一个值。
        
    - 它返回一个对象，格式为：{ value: key值, done: false }。
        
    - 第一次调用 next()，拿到的就是 Map 中的 **第一个** 元素。
        
3. .value:
    
    - 从上面的对象中取出真正的 key。
