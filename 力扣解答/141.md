有环无环 可以使用快慢双指针 如果有环的话 那么指针会相遇 否则不会 fast指针会走向null
fast走两步 slow走一步 那么如果while(fast&&fast.next) 如果有环的话 这里会死循环
必然会`slow===fast`   相遇时 fast会比slow多走一圈 所以时间复杂度为O(N)

```js
var hasCycle = function(head) {

    let fast=head,slow=head

    while(fast&&fast.next){

        fast=fast.next.next

        slow=slow.next

        if(slow==fast) return true
 
    }
        return false //能走出while循环 而且没有return true 说明是无环

};
```
