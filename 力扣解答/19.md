双指针 有可能删除的是队头  所以我们使用dummynode 
让slow和fast相距n  这样slow指向倒数第n+1 
   slow.next=slow.next.next即可删除第n个节点 不需要delete
提示说了
- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`
```
var removeNthFromEnd = function(head, n) {

    //双指针

    const dummyNode=new ListNode(-1,head)

    let step=0

    let cur=slow=dummyNode

    while(step<n){//执行n次

      cur=cur.next//cur指向正数第n+1个

      step++

    }

    while(cur.next){//判断cur为链表最后一个元素 是 while(cur.next)而不是   //while(cur)

      cur=cur.next

      slow=slow.next

    }

    slow.next=slow.next.next

    return dummyNode.next

};
```

双指针 cur和slow差距n个节点  cur指向第n+1 slow指向第1个差距为n
当cur指向最后一个时 slow指向倒数第n+1个元素 slow.next=slow.next.next来跳过第n个元素
