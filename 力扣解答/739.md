栈这一块整体不太好
整体就是找后面第一个比该数值大的索引 记录索引相减
我们用栈来记录索引  这里栈是一个单调递减的栈 将时间复杂度缩减到O(n)
思路 就是我们遍历一遍数组 遇到比栈中索引对应数组值更大的值 我们将对应的差值 记录到res数组中
并弹出栈中索引   最后我们都需要将当前遍历元素索引压入栈中 

```js
var dailyTemperatures = function(temperatures) {

    const stack=[]

    const res=new Array(temperatures.length).fill(0)
	//我们这里直接就都赋值为0  如果没有满足的默认就是0了
    for (let i = 0; i< temperatures.length; i++) {

        while(stack.length>0&&temperatures[stack[stack.length-1]]<temperatures[i]){

            let index=stack[stack.length-1]

            res[index]=i-index

            stack.pop()

        }

        stack.push(i)

    }

    return res

};
```
