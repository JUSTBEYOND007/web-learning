# **摩尔投票算法思想（Boyer–Moore）**

### **一句话核心：**

> **用“投票”抵消掉不同的数，多数元素一定能存活到最后。**

为什么？

- 多数元素出现次数 > n/2
    
- 其他所有数出现次数 < n/2
    
- 所以“一对一”消耗后，多数元素必定剩下。
    

---

# ⭐ **算法流程（牢记）**

我们维护两个变量：

- **candidate**：当前候选多数元素
    
- **count**：票数
    

遍历数组：

1. **如果 count == 0，则把当前数作为 candidate**
    
2. **如果当前数 == candidate，则 count++**
    
3. **否则 count--**
    

遍历结束后，candidate 就是多数元素。

```js
var majorityElement = function(nums) {

    let count=0//count记录的是相对投票数量

    let res=0

    for (const element of nums) {

        if(count===0)//为0的时候替换为当前元素 

            res=element

        if(res===element)

            count++

        else count-- 
	//如果抵消后 count 变为 0，说明截至目前双方票数打平。  
	//此时不立刻更换 res，等下一次循环遇到新的 element，再进行替换。
    }

    return res

};
```
