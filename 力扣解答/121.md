买卖股票的最佳时机
我们就是计算最大利润 但是需要注意时间前后
思路就是求数组中假如我们某一天中我们卖出的最大利润   然后我们遍历所有假如我们该天卖出取得的最大值  
计算我们某一天中我们卖出的最大利润  就是需要知道我们之前最小值时买入的点 我们用pre来记录
同时实时更新pre即可
我们需要最大利润 = 某天卖出价 - 某天前的最小买入价  取其中最大值即可
```js
var maxProfit = function(prices) {

    let pre=prices[0]

    let ans=0

    for (let index = 0; index < prices.length; index++) {

        ans=Math.max(ans,prices[index]-pre)

        pre=Math.min(pre,prices[index])

    }

    return ans

};
```
