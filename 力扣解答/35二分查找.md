二分查找必须是有序的 这里代码写的必须是升序的
我们使用while循环 while(left<=right) 来判断

在二分查找循环结束时，都满足下面的关系：

1. 区间 [0, right] 中的值都 `< target`

2. 区间 [left, end] 中的值都 `>= target`

所以如果没有找到left位置就是我们要插入的位置

```js
var searchInsert = function(nums, target) {

    let left=0,right=nums.length-1//左右端点

    while(left<=right){

        let mid=Math.floor((left+right)/2)

        if(nums[mid]<target){

            left=mid+1

        }else if(nums[mid]>target){

            right=mid-1

        }else return mid

    }

    return left

};
```
