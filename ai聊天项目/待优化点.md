## 优化需求

### 1. 添加代码拆分（Code Splitting）

在 build.rollupOptions.output 中配置 manualChunks，将第三方库拆分到独立的 chunk：

- react-vendor: React 核心库（react, react-dom, react-router-dom）
- router: React Router（react-router-dom 单独拆分）
- antd: Ant Design UI 库（antd, @ant-design/icons, @ant-design/x）
- http: HTTP 请求库（axios, event-source-polyfill）
- state: 状态管理库（zustand）
- vendor: 其他第三方库（node_modules 中的其他依赖）

### 2. 优化输出文件名

配置 chunkFileNames、entryFileNames、assetFileNames，使用 hash 命名：

- chunkFileNames: 'js/[name]-[hash].js'
- entryFileNames: 'js/[name]-[hash].js'
- assetFileNames: 分类存储（images/、fonts/、media/、css/）

### 3. 添加构建优化配置

- chunkSizeWarningLimit: 提高到 1000KB（减少警告）
- sourcemap: false（生产环境不生成 sourcemap）
- minify: 'terser'（使用 terser 压缩）
- terserOptions: 压缩选项（drop_console, drop_debugger）

### 4. 添加开发环境代理配置

在 server 中配置代理，解决开发环境跨域问题：

- proxy: '/api' -> 后端地址（假设是 [http://localhost:8080）](http://localhost:8080%EF%BC%89/)
- changeOrigin: true
- rewrite: 去掉 /api 前缀

### 5. 性能分析工具（可选）

添加 rollup-plugin-visualizer 插件，生成打包分析报告：

- open: false（不自动打开，避免影响构建速度）
- filename: 'dist/stats.html'
- gzipSize: true（显示 gzip 后的体积）
