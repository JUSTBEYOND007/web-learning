## 项目中虚拟列表的实现
<font color="#9B59B6">通过scrolltop和记录元素高度的map 进行二分查找 来找到对应的第一个元素索引
然后我们通过const viewportBottom = scrollTop + containerHeight 和map来查找最后一个元素的索引</font>


1. 初始时用 `estimatedHeight` 生成 offsetTop → 计算 startIndex/endIndex
    
2. 渲染可视元素 → 获取真实高度 → 更新 Map
    
3. 下次滚动时，使用 **已知高度 + 已知 offsetTop** → startIndex/endIndex 更精准
    

- **未渲染的元素**仍使用 `estimatedHeight`
    
- **渲染过的元素**使用真实高度
    
- **增量更新**保证性能 → 不必每次从头累加所有元素高度
用一个 map 用来存储已经滑动过的元素高度信息，包括元素自身的高度和它之前的总高度

### 2. 不定高虚拟列表的核心原理

如果自己实现，核心思路如下：

#### 核心思路

1. 高度缓存：维护一个 Map<itemIndex, height> 记录每个元素的实际高度

2. 动态测量：使用 ResizeObserver 监听元素高度变化

3. 位置计算：根据缓存的高度计算每个元素的 top 位置

4. 可见区域：只渲染视口内的元素

#### 伪代码实现
```js
interface VirtualListProps<T> {
  items: T[]
  itemHeight?: number  // 估算高度（不定高时作为初始值）
  containerHeight: number
  renderItem: (item: T, index: number) => ReactNode
}

function VirtualList<T>({ items, itemHeight = 50, containerHeight, renderItem }: VirtualListProps<T>) {
  const [heights, setHeights] = useState<Map<number, number>>(new Map())
  const [scrollTop, setScrollTop] = useState(0)
  const containerRef = useRef<HTMLDivElement>(null)
  const itemRefs = useRef<Map<number, HTMLDivElement>>(new Map())

  // 1. 计算每个元素的 top 位置（基于缓存的高度）
  const getItemTop = (index: number): number => {
    let top = 0
    for (let i = 0; i < index; i++) {
      top += heights.get(i) || itemHeight  // 使用缓存高度或估算高度
    }
    return top
  }

  // 2. 计算总高度
  const totalHeight = items.reduce((sum, _, index) => {
    return sum + (heights.get(index) || itemHeight)
  }, 0)

  // 3. 计算可见区域
  const visibleRange = useMemo(() => {
    const start = findStartIndex(scrollTop, heights, itemHeight)
    const end = findEndIndex(scrollTop, containerHeight, heights, itemHeight, items.length)
    return { start, end }
  }, [scrollTop, containerHeight, heights])

  // 4. 使用 ResizeObserver 测量实际高度
  useEffect(() => {
    const observers = new Map<number, ResizeObserver>()
    
    itemRefs.current.forEach((element, index) => {
      if (!element) return
      
      const observer = new ResizeObserver((entries) => {
        for (const entry of entries) {
          const height = entry.contentRect.height
          setHeights(prev => {
            const newHeights = new Map(prev)
            newHeights.set(index, height)
            return newHeights
          })
        }
      })
      
      observer.observe(element)
      observers.set(index, observer)
    })

    return () => {
      observers.forEach(observer => observer.disconnect())
    }
  }, [visibleRange])

  // 5. 渲染可见元素
  const visibleItems = items.slice(visibleRange.start, visibleRange.end + 1)

  return (
    <div
      ref={containerRef}
      style={{ height: containerHeight, overflow: 'auto' }}
      onScroll={(e) => setScrollTop(e.currentTarget.scrollTop)}
    >
      <div style={{ height: totalHeight, position: 'relative' }}>
        {visibleItems.map((item, relativeIndex) => {
          const absoluteIndex = visibleRange.start + relativeIndex
          const top = getItemTop(absoluteIndex)
          
          return (
            <div
              key={absoluteIndex}
              ref={(el) => {
                if (el) itemRefs.current.set(absoluteIndex, el)
              }}
              style={{
                position: 'absolute',
                top: `${top}px`,
                width: '100%'
              }}
            >
              {renderItem(item, absoluteIndex)}
            </div>
          )
        })}
      </div>
    </div>
  )
}
```

### 3. 关键算法：查找可见范围

// 二分查找：找到第一个可见元素的索引
```js
// 二分查找：找到第一个可见元素的索引
function findStartIndex(
  scrollTop: number,
  heights: Map<number, number>,
  estimatedHeight: number
): number {
  let low = 0
  let high = heights.size - 1
  
  while (low <= high) {
    const mid = Math.floor((low + high) / 2)
    const top = getItemTop(mid, heights, estimatedHeight)
    
    if (top <= scrollTop) {
      low = mid + 1
    } else {
      high = mid - 1
    }
  }
  
  return Math.max(0, high)
}

// 查找最后一个可见元素的索引
function findEndIndex(
  scrollTop: number,
  containerHeight: number,
  heights: Map<number, number>,
  estimatedHeight: number,
  totalItems: number
): number {
  const viewportBottom = scrollTop + containerHeight
  let low = 0
  let high = totalItems - 1
  
  while (low <= high) {
    const mid = Math.floor((low + high) / 2)
    const top = getItemTop(mid, heights, estimatedHeight)
    const height = heights.get(mid) || estimatedHeight
    const bottom = top + height
    
    if (bottom < viewportBottom) {
      low = mid + 1
    } else {
      high = mid - 1
    }
  }
  
  return Math.min(totalItems - 1, low)
}
```

### 5. 优化点

1. 高度缓存：避免重复测量

2. ResizeObserver：自动监听高度变化

3. 缓冲区域：渲染可见区域上下各多渲染几个元素，减少滚动时的闪烁

4. 防抖：高度更新时防抖，避免频繁重算
