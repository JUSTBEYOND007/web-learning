```
用户点击发送消息
    ↓
submitMessage()
    ↓
1. 创建/选择会话（如果没有 selectedId）
    ↓
2. 添加用户消息到 UI（addMessage，role: 'user'）
    ↓
3. 调用 createSSEAndSendMessage()
    ↓
    ├─→ 步骤 A：建立 SSE 连接
    │   eventSourceRef.current = createSSE(chatId)
    │   → 连接到：GET /chat/getChat/${chatId}
    │   → 设置 onmessage 处理器（准备接收流式数据）
    │
    └─→ 步骤 B：发送 POST 请求
        sendMessage(chatId, message, fileId)
        → POST /chat/sendMessage
        → Body: { id: chatId, message: '...', fileId: '...' }
    ↓
后端处理：
    ↓
4. 收到 POST /chat/sendMessage
   → 保存用户消息到数据库
   → 调用大模型 API 生成回复
    ↓
5. 大模型开始生成回复（流式）
   → 通过已建立的 SSE 连接推送数据
   → 发送：{ type: 'chunk', content: '你' }
   → 发送：{ type: 'chunk', content: '好' }
   → 发送：{ type: 'chunk', content: '！' }
   → ...
   → 发送：{ type: 'complete', content: '你好！我是AI助手...' }
    ↓
前端接收（SSE onmessage）：
    ↓
收到 { type: 'chunk', content: '你' }
    → addChunkMessage('你')
    → UI 更新：显示 "你"
    ↓
收到 { type: 'chunk', content: '好' }
    → addChunkMessage('好')
    → UI 更新：显示 "你好"
    ↓
收到 { type: 'complete', content: '...' }
    → setInputLoading(false)
    → 流式传输完成
```
