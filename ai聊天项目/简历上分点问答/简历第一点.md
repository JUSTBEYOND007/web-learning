SparkMD5 解决了大文件无法一次性读入内存的问题，确保了传输的稳定性和准确性。
MD5 是一种常见的哈希算法（消息摘要算法），能把任意长度的数据压缩成固定的 128 bit（32位十六进制）的摘要。用于校验和唯一标识，不用于加密存储

**文件级哈希（采样计算）：**

- 作为文件的唯一标识（fileId）
- 用于秒传判断（服务器检查文件是否已存在）
- 用于分片合并时关联所有分片
- 为了性能优化，采用采样策略（首尾全量 + 中间取少量字节）

**2. 分片级哈希（全量计算）：**

- 对每个分片做完整的 MD5 计算
- 上传时发送给后端，后端也计算哈希进行完整性校验
- 防止分片在传输过程中损坏或被篡改

## 完整数据结构拆解

### 1. 最外层：`Map<string, ...>`

**作用：** 存储多个会话的消息

```
Map<string, MessageProps[]>
```

| 类型        | 含义           | 示例                                   |
| --------- | ------------ | ------------------------------------ |
| **Key**   | 会话ID（chatId） | `"abc-123"`, `"def-456"`             |
| **Value** | 该会话的消息数组     | `[{content, role}, {content, role}]` |

---

### 2. 中间层：`MessageProps[]`

**作用：** 单个会话的消息列表

```
MessageProps[] = [  { content: [...], role: 'user' },  { content: [...], role: 'system' },  { content: [...], role: 'user' }]
```

---

### 3. 最内层：`MessageProps`

**作用：** 单条消息的结构

```
{  content: MessageContent[],  // 消息内容（支持多种类型）  role: Role                 // 消息角色}
```

---

### 4. `content` 字段：`MessageContent[]`[](https://zread.ai/JUSTBEYOND007/ai-chat/17-file-upload-with-chunking-strategy#4-content-%E5%AD%97%E6%AE%B5messagecontent)

**作用：** 单条消息可以包含多种类型的内容

```
MessageContent[] = [  { type: 'text', content: '你好' },  { type: 'image', content: 'http://...' }]
```

**上传带哈希的分块，返回分块哈希是什么意思？**
这是一种**双重哈希校验机制**：

1. **前端计算哈希** - 对分片数据计算 MD5，作为完整性标识
2. **发送哈希+数据** - 同时发送分片数据和哈希值
3. **服务器验证** - 服务器也计算哈希，与前端发送的对比
4. **返回确认** - 服务器返回自己计算的哈希值，确认接收无误

**作用：**

- 防止传输过程中数据损坏（网络问题）
- 防止恶意篡改（安全性）
- 提供上传确认（前端可再次验证）
