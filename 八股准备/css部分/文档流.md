文档流（也叫标准流）是浏览器默认排列 HTML 元素的方式。
- **块级元素**（block）：纵向排列（上下排列），宽度默认撑满父元素
    
- **行内元素**（inline）：水平排列（从左到右），按内容宽度
    

**特点：**

- 元素按 HTML 顺序排列
    
- 后面的元素会受到前面元素的影响（位置会跟随前面的元素）

# ✅ **2. 什么叫脱离文档流？**

> 脱离文档流 = 元素不再占据文档流原来的空间，其他元素在排布时不会受它影响。

# **2. 什么叫脱离文档流？**

> 脱离文档流 = 元素不再占据文档流原来的空间，其他元素在排布时不会受它影响。

**常见脱离文档流方式：**

|方法|说明|
|---|---|
|`position: absolute`|相对于最近的已定位祖先定位，脱离文档流|
|`position: fixed`|相对于视口定位，脱离文档流，滚动不动|
|`position: sticky`|在滚动到某个位置前保持文档流，但一旦固定就脱离文档流（部分脱离）|
|`float`|浮动元素脱离文档流，父容器高度可能塌陷|
|`display: none`|元素完全消失，占位消失|

> 注意：`relative` **不会脱离文档流**，只是移动视觉位置，元素仍占原来的空间
