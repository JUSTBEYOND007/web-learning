事件流指事件在 DOM 树中传播的顺序，分为捕获阶段（document → target）、目标阶段（target 元素自身触发）和冒泡阶段（target → document）。DOM2 事件可以选择在捕获或冒泡阶段触发，事件委托就是利用冒泡在父元素统一处理子元素事件，阻止传播可用 stopPropagation 或 stopImmediatePropagation。



**DOM2 事件（DOM Level 2 Event）** 是 **W3C 标准化后的事件模型**，主要特点是：

1. **事件绑定使用 `addEventListener`**
    
    element.addEventListener(type, handler, useCapture);
    
    - `type`：事件类型，如 `'click'`
        
    - `handler`：事件处理函数
        
    - `useCapture`：是否在捕获阶段触发（true → 捕获，false → 冒泡，默认 false）
        
2. **支持三个阶段**：
    
    - 捕获阶段（Capture Phase）
        
    - 目标阶段（Target Phase）
        
    - 冒泡阶段（Bubble Phase）
        
3. **同一元素可绑定多个事件处理函数**
    
    - DOM0 `element.onclick = fn` 会覆盖原有绑定
        
    - DOM2 不会覆盖，可以多个同时存在
        
4. **兼容事件对象 `event`**
    
    - `event.target`：触发事件的具体元素
        
    - `event.currentTarget`：绑定事件的元素
        
    - `event.stopPropagation()`、`event.preventDefault()`
