跨域是指浏览器在请求不同源的资源时受到同源策略的限制。

重点关键词：   浏览器请求同一个域名的 Nginx 服务器，然后由 Nginx 将请求转发到后端 API 服务器    Nginx 和后端服务器之间的通信不受浏览器同源策略限制



浏览器存在同源策略限制，当协议、域名或端口不同的时候就会产生跨域。

我们可以使用 Nginx 的反向代理功能来解决跨域问题。具体做法是让浏览器请求同一个域名的 Nginx 服务器，然后由 Nginx 将请求转发到后端 API 服务器。

由于浏览器只和 Nginx 通信，因此请求是同源的，而 Nginx 和后端服务器之间的通信不受浏览器同源策略限制，从而解决跨域问题。
