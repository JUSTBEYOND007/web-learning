
transform / opacity 只触发合成

- transform 只改变 **渲染坐标系**，**不改变元素的 box model**
    
- 元素实际的宽高、位置、布局信息不变
    
- 浏览器可以把元素放到单独 **合成层**，用 GPU 直接移动/缩放 → **不触发重排，不触发重绘**


```
回流（Reflow）是当元素的几何属性或内容发生变化时，浏览器重新计算元素布局的过程，会影响元素及其子元素和父元素的位置与大小，开销较大；重绘（Repaint）是当元素外观（颜色、背景、可见性等）发生变化，但不影响布局时，浏览器只重新绘制像素，开销相对较小；优化原则是尽量减少回流、合并 DOM 操作、使用 transform 或 opacity 等不会触发回流的属性。
```
