这对“双子星”逻辑运算符是 JavaScript 开发中使用频率最高的操作符。要记好这份笔记，核心在于理解它们的**“短路特性”（Short-circuiting）**。

---

## 1. `&&` (逻辑与 - Logical AND)

核心逻辑：找“假” (Falsy)

它从左往右计算，直到遇到第一个“假值”，就立刻停止并返回。如果全部为真，则返回最后一个。

- **执行过程：**
    
    1. 看左边，是假吗？如果是，**停**，返回左边的值。
        
    2. 如果左边是真，看右边，返回右边的值。
        
- **笔记重点：**
    
    - **守护功能**：只有前面是真的，后面才会执行。
        
    - **安全取值**：防止访问 `null` 或 `undefined` 的属性报错。
        

**代码示例：**

JavaScript

```
// 1. 用于赋值
const name = user.isLoggedIn && user.name; // 如果登录了，拿到名字；没登录，拿到 false/null

// 2. 用于执行函数 (代替短 if)
showSuccessMessage && sendNotification(); // 只有显示成功了，才发通知

// 3. 结果演示
console.log("apple" && "banana"); // "banana" (全是真，取最后)
console.log(0 && "banana");      // 0 (第一个就是假，停)
```

---

## 2. `||` (逻辑或 - Logical OR)

核心逻辑：找“真” (Truthy)

它从左往右计算，直到遇到第一个“真值”，就立刻停止并返回。如果全部为假，则返回最后一个。

- **执行过程：**
    
    1. 看左边，是真吗？如果是，**停**，返回左边的值。
        
    2. 如果左边是假，看右边，返回右边的值。
        
- **笔记重点：**
    
    - **保底功能**：提供默认值。
        
    - **多选一**：只要有一个满足条件即可。
        

**代码示例：**

JavaScript

```
// 1. 提供默认值 (最常用)
const theme = userTheme || "light"; // 如果用户没设置主题，默认用 "light"

// 2. 结果演示
console.log("apple" || "banana"); // "apple" (第一个就是真，停)
console.log("" || "banana");      // "banana" (第一个是假，看第二个)
console.log(false || 0);          // 0 (全是假，取最后)
```

---

## 3. 对比总结表（防混淆）

| 特性 | && (与) | || (或) |

| :--- | :--- | :--- |

| 口诀 | 找假（有假即假） | 找真（有真即真） |

| 短路行为 | 遇到 Falsy 就停 | 遇到 Truthy 就停 |

| 典型场景 | “只有...才...” (执行权限/安全访问) | “如果不...就...” (设置默认值) |

| 返回值 | 返回第一个遇到的假值，或最后一个真值 | 返回第一个遇到的真值，或最后一个假值 |

---

## 4. 补充笔记：什么是“假值” (Falsy)？

在 JS 中，只有以下 **6 个值**在逻辑运算中会被当作 `false`：

1. `false`
    
2. `0` (包括 `-0` 和 `0n`)
    
3. `""` (空字符串)
    
4. `null`
    
5. `undefined`
    
6. `NaN`
    

_其他所有值（包括空数组 `[]` 和空对象 `{}`）都是 **真值 (Truthy)**。_

---

## 5. 进阶提醒：空值合并运算符 `??`

有时候 || 会有坑。比如：

const count = userCount || 10;

如果 userCount 刚好是 0，|| 会认为它是假，从而返回 10。但这可能不是你想要的（0 也是一个有效的数字）。

**这时候笔记里可以补一笔：**

> 如果只想在 null 或 undefined 时触发默认值，用 ??。
> 
> 0 || 10 结果是 10
> 
> 0 ?? 10 结果是 0
