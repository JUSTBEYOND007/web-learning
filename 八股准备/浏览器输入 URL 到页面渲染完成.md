```js
1. 输入 URL
2. 浏览器检查缓存
3. DNS 解析（域名 → IP）
4. TCP 三次握手建立连接
5. 浏览器发送 HTTP 请求
6. 服务器处理请求并返回响应
7. 浏览器接收响应
8. 解析 HTML 构建 DOM 树
9. 解析 CSS 构建 CSSOM 树
10. 合并 DOM + CSSOM → Render Tree
11. Layout（布局）
12. Paint（绘制）
13. Composite（合成） → 页面显示
```


缓存检查：
```js
						实际流程是：
						
						浏览器请求资源  
						      ↓  
						先检查 强缓存  
						      ↓  
						强缓存命中 → 直接使用缓存（不发请求）  
						      ↓  
						强缓存未命中  
						      ↓  
						再走 协商缓存  
						      ↓  
						服务器判断资源是否变化
						
						所以可以理解为：
						
						强缓存  >  协商缓存
```
