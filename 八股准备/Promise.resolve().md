| **传入参数 value**    | **Promise.resolve(value) 的结果状态** | **结果原因**               |
| ----------------- | -------------------------------- | ---------------------- |
| **普通值** (如 `123`) | **Fulfilled** (成功)               | 它直接包装这个值               |
| **成功的 Promise**   | **Fulfilled** (成功)               | 它直接返回这个 Promise        |
| **失败的 Promise**   | **Rejected** (失败)                | 它“跟随”了传入 Promise 的失败状态 |
| **Thenable 对象**   | **取决于该对象的 .then 逻辑**             | 它会尝试执行该对象的 `.then`     |
