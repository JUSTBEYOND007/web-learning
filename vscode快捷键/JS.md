###  为什么要包一层箭头函数？

通常在 React 中绑定事件有两种情况：

- **情况 A：不需要传参数**  
    如果你的函数不需要参数，你可以直接写函数名（引用）：
    
    codeJsx
    
    ```
    // ✅ 这样是可以的，因为 handleDelete 是一个函数引用，没有括号 ()
    onClick={handleDelete}
    ```
    
- **情况 B：需要传参数（你图中的情况）**  
    因为你需要把 data 传进去，所以你必须写括号 (data)。但是一旦写了括号，JS 就会立即执行它。  
    为了解决“既要传参”又“不能立即执行”的矛盾，我们需要用一个**匿名函数（箭头函数）**把它包起来：
    
    codeJsx
    
    ```
    // ✅ 定义一个匿名函数，点击时触发这个匿名函数，匿名函数内部再去执行真正的逻辑
    onClick={() => handleDelete(id)}
    ```
