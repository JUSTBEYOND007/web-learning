### 我们的虚拟列表 `useVirtualList` 是怎么实现的？

核心代码：`src/hooks/useVirtualList.ts`（你附的那段）

#### 1. Hook 的入参和返回值

```ts
export const useVirtualList = <T = any>(
  items: T[],
  options: { itemHeight: number; containerHeight: number; buffer?: number }
)
```

- **`items`**：完整数据列表（比如 1000 条审批记录）
- **`itemHeight`**：每一行的固定高度（px）
- **`containerHeight`**：可视区域高度
- **`buffer`**：上下预渲染的缓冲行数（默认 5 行）

返回：

- `containerRef`：滚动容器的 `ref`
- `visibleItems`：当前需要渲染的那一小段数据
- `totalHeight`：整个列表的理论总高度（用于生成占位容器）
- `offsetY`：当前可视内容相对顶部的位移量，用来通过 `translateY` 把 `visibleItems` 挪到正确位置
- `handleScroll`：绑定到容器的 `onScroll`，实时更新 `scrollTop`

#### 2. 关键逻辑：只渲染「可见 + 缓冲」的那一段

```ts
const [scrollTop, setScrollTop] = useState(0);

const totalHeight = items.length * itemHeight;
const visibleCount = Math.ceil(containerHeight / itemHeight);

// 计算当前滚动对应的起始/结束索引，加上 buffer 缓冲
const startIndex = Math.max(0, Math.floor(scrollTop / itemHeight) - buffer);
const endIndex = Math.min(
  items.length - 1,
  startIndex + visibleCount + buffer * 2
);

// 截取这一小段数据作为 visibleItems
const visibleItems = items
  .slice(startIndex, endIndex + 1)
  .map((data, index) => ({
    index: startIndex + index,
    data,
  }));

const offsetY = startIndex * itemHeight;
```

含义：

- **`scrollTop`**：当前滚动条偏移
- 根据 `scrollTop` 和 `itemHeight`，算出当前屏幕应该从第几条开始显示（`startIndex`）
- 只取 `startIndex ~ endIndex` 这一小段数据给组件渲染
- 外层用一个高度为 `totalHeight` 的占位 `div`，内部再用 `transform: translateY(offsetY)` 把这一小段内容挪到正确位置 → 视觉上等价于完整列表，但 DOM 只有几十个节点

#### 3. 滚动事件驱动

```ts
const handleScroll = useCallback((e: React.UIEvent<HTMLDivElement>) => {
  setScrollTop(e.currentTarget.scrollTop);
}, []);
```

- 每次滚动时更新 `scrollTop`，触发上面的 `startIndex/endIndex` 重新计算，从而「滑动窗口」地更新 `visibleItems`

#### 4. 在审批列表中的使用

在 `src/pages/Approval/index.tsx` 里：

```ts
const {
  containerRef,
  visibleItems,
  totalHeight,
  offsetY,
  handleScroll,
} = useVirtualList<ApprovalItem>(filteredItems, {
  itemHeight: 100,
  containerHeight: 600,
  buffer: 5,
});
```

渲染时：

- 外层 `div` 高度设为 `totalHeight`
- 内层 `div` 做 `transform: translateY(offsetY)`，只 `map(visibleItems)` 渲染当前这一小段审批项
