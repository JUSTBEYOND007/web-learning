在 **闭包（closure）** 中，被“延长生命周期”的那个变量，一般称为： **自由变量（Free Variable）**

这是最标准、最准确的叫法。

**自由变量** 指的是：  
👉 **既不是当前函数的局部变量，也不是全局变量，却在函数内部被使用的变量**。

闭包会“捕获”这些自由变量，使得它们不会在函数执行完后销毁，而是继续保存在内存中。

📌 **闭包（closure）会捕获其外层作用域中的自由变量（free variables），从而延长这些变量的生命周期。**


闭包是什么 举一个你在开发中实际用到的闭包的例子

闭包就是函数和它的定义时作用域组合。在节流函数里，我用闭包保存上一次函数执行的时间戳，这样每次滚动事件触发时，内部函数都能访问这个状态，实现限制函数执行频率的功能


```js
function throttle(fn, delay) {
  let lastTime = 0; // 闭包变量，记录上一次执行时间

  return function(...args) {
    const now = Date.now();

    if (now - lastTime >= delay) {
      fn.apply(this, args);
      lastTime = now; // 更新上一次执行时间
    }
  }
}

// 实际使用场景：滚动事件节流
window.addEventListener('scroll', throttle(() => {
  console.log('滚动事件触发！');
}, 200));
```
